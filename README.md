# 品牌战略分析 · Brand Strategy Analysis

**从政府、企业家与农户的访谈中，找出产业长期停滞的关键瓶颈，把发现写成有深度、能指导政府与企业决策的品牌战略报告。**

品牌战略分析是面向区域公用品牌与特色农产品产业的开源 AI 研究技能。它带你追溯关键事件、核对经营记录、比较同行条件，让报告说清问题为什么反复出现，以及下一步为什么这样做。

技能按**路由 → 具体工作流 → 基本单元**组织：先识别当前任务，再展开对应过程，最后把动作拆到能照着完成。新人用它设计访谈、整理日报、追查证据缺口；专家与 AI 共同核对资料、推敲机制和战略选择，形成随证据迭代的人机协同研究过程。

## 适合谁

适合做区域品牌和农业产业项目的策划咨询团队、组织访谈的调研负责人，以及希望学习研究方法的学生和项目参与者。

例如，你准备访谈100位政府经办者、企业家、合作社负责人和农户，希望让缺乏经验的同事参与。这个技能会帮助你把任务展开为：访谈哪些人、为什么选他们、每类问什么、遇到含糊回答怎么追问、如何记录，以及第一批访谈结束后怎样调整下一批安排。

## 能帮你做什么

| 你遇到的任务 | 技能帮助你形成的成果 |
|---|---|
| 明天要去调研，还没想清楚问什么 | 按角色区分的访谈提纲、追问分支、观察清单和记录表 |
| 收到一批访谈转写，大家说法不同 | 事实与观点整理、角色立场比较、调研日报和下一轮补访问题 |
| 当地都说缺品牌，但原因讲不清 | 围绕目标的诊断、关键堵点、可能原因和验证办法 |
| 想找到有竞争力的定位或大单品 | 本地与竞品的同口径比较、候选方向、取舍依据和试验安排 |
| 几个市场都想进入，资源又有限 | 进入路径比较、可执行的工程组合、首批验证与下一阶段条件 |
| 增加品牌标识后销量变化，想知道是否值得继续投 | 区分品牌、曝光与经营变化的比较设计，以及对应投入安排 |
| 需要把策略变成具体方案 | 经营主体、产品与渠道安排、执行步骤、材料和检查标准 |
| 已有报告，需要深化或汇报 | 论证补强、章节修改、决策汇报结构和PPT逐页内容 |

## 快速开始

### 1. 下载技能

在本页选择 **Code → Download ZIP**，解压后保留完整的 `brand-strategy-analysis` 文件夹。也可以使用 Git：

```sh
git clone https://github.com/qingmingyiyang/brand-strategy-analysis.git
```

### 2. 让 AI 读取技能

使用能够读取本地 Markdown 文件的 AI 助手，提供解压后的目录位置，让它先读取 `SKILL.md`。入口会引导它先读取当前任务的主方法，再按具体缺口补充 `references/` 中的相关部分。

将下面的路径换成你的实际路径，直接发送：

```text
请读取 <技能目录的实际路径>/SKILL.md，使用品牌战略分析技能。

我正在做某地的农产品品牌项目，明天要访谈企业、合作社和政府。
本轮想准备一份没有调研经验的人也能使用的访谈材料。
已有项目背景和资料见附件。

请先帮我明确本轮要弄清的问题，再按受访者类型设计提纲、追问分支和记录表。
```

如果你的助手支持技能安装，也可以把完整目录放入该工具指定的技能目录，按其方式加载。

### 3. 带着新材料继续

访谈回来后，可以接着说：

```text
这是今天的访谈转写。请整理调研日报，比较各方说法，说明目前能判断什么、还缺什么证据，并调整明天的访谈提纲。
```

每次补充材料，助手都会沿当前任务检视判断，说明新发现改变了什么，以及下一步最值得问什么。

## 它怎样开展研究

**明确目标 → 获取事实 → 形成初步诊断 → 针对性补证 → 比较策略 → 设计行动 → 根据结果调整。**

这条流程可以从你当前的进度开始。下面说明贯穿其中的方法。

### 与AI一起训练批判性思维

围绕理解问题、提出假设并设计框架、拆解问题、质疑论证、迭代验证和分析判断六项能力开展研究。先从事实形成初步解释，再分清事实、解释、价值目标和行动选择，让AI补充其他解释与反例，回到原始材料核验，形成有依据的选择。方法包含可直接填写的假设句式和四层拆解示例，见[六项判断与人机协同](references/reasoning-and-evidence.md#ai时代的六项判断能力)。已有判断直接复用，按当前缺口进入相应环节。

### 从事实形成判断

先了解具体发生了什么，再分析为什么。企业、政府、消费者和研究者各有自己的视角，技能会引导你比较他们掌握的信息、利益诉求和实际记录，找出值得核验的差异。

例如听到产品卖不上价，会继续追问：哪种规格、卖给谁、与谁比较、哪次交易没有谈成？这些问题帮助你把笼统归因变成可以调查的事实。

### 从小切口深入到关键机制

围绕一个影响决定的小问题层层追问。比如加工投资为什么多年未能落地，可以从其中一次中止切入：当时准备做什么，谁在何时退出，哪些条件没有谈成？再核对供货约定、收购记录和不同年份的选择，追问是什么安排让各方始终难以持续合作。诊断据此解释问题为何反复出现，并指导下一步验证与投入。

研究深度体现在每次追问都增加解释力，最终能说明某项策略为什么值得做、怎样验证。详细示例见[小切口与大纵深](references/writing-and-structure.md)。

### 把行动拆到普通人能执行

最小单元的标准是：交给一个没有经验的人，照着材料也能完成。

以企业家访谈为例，材料要说明找谁、围绕哪次经营事件提问、怎样追问退出原因、核对哪些记录，以及何时补访政府经办者和农户。交付还包括开场话术、记录样例和检查方法，执行者知道怎么开始，也知道说法冲突时如何继续取证。具体见[最小单元与交付标准](references/output-contracts.md)。

希望边做边学时，可以直接说：请先用最简单的话讲清基础，带我做一个小步骤，再根据我的操作逐步加深。助手会从整体目标倒推眼前需要的基础，示范、反馈，再把小单元组合起来。例如，先学会记录一笔交易，再比较两笔交易，随后才分析价格差异的原因。已有能力直接复用，具体见[教学短循环](references/collaborative-inquiry.md#由繁入简再由简入繁)。

## 从一次调研到完整规划

你可以只做一个环节，也可以逐步形成 **1+4+1**：

| 报告 | 内容 |
|---|---|
| 1份总体报告 | 行业与本地现状、品牌定位、能力与产品、认知与推广、市场机制、企业生态、政府支撑和三年行动 |
| 4份专题报告 | 供应链与交易中心、内容与生态电商、产地场景、渠道策略与运营 |
| 1份决策汇报 | 凝练核心问题、策略依据、行动安排和需要作出的决定 |

已有总体定位时，可以直接深化某份专题。例如：

```text
基于已确认定位，先深化电商专题。请把选品、内容、成交、履约和复购串起来，说明谁来经营、收益如何形成，以及第一阶段具体怎么做。
```

## 运行方式与版本

使用能够读取本地文件的 AI 助手，提供项目背景和现有材料即可开始。访谈资料可直接提供文字转写；需要外部资料时使用联网工具，任务较大时可按助手支持的方式组织多Agent协作。

当前版本为 **0.30.1**。你可以从访谈设计、问题诊断或某份专题进入，也可以用[贯穿练习](evals/manual-case.md)熟悉方法。各版变化见[更新记录](CHANGELOG.md)。[三个公开案例](https://github.com/qingmingyiyang/brand-strategy-analysis/blob/main/evals/real-cases.md)展示了如何比较解释、修改访谈材料，并根据新证据调整判断。你可以查看完整答卷和评审过程。

## 维护与打包

`public-files.txt`是公共文件清单。新增公共材料时更新清单，再运行：

```sh
python scripts/build_public.py --source . --check-only
python scripts/build_public.py --source . --output brand-strategy-analysis.zip
```

脚本检查版本、文件引用和用例编号，按公共清单生成分发包。私人案例保存在本地的`references/private/`，发布清单与Git忽略规则已配置对应的排除项。
