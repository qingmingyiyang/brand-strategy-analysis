# 品牌战略分析 Skill v0.6.2

核心目的：把专家的研究判断转化为普通人可以执行、能够随证据迭代的调研工作流。覆盖研究设计、分批执行、证据复盘与下一轮调整，让用户知道做什么、为什么做以及如何根据发现改变做法。

用于区域公用品牌与特色农产品产业的研究、定位、经营设计和执行规划。这是持续迭代的初级版本；文档结构已检查，真实执行效果仍需通过实践检验。

全报告以最小单元为写作指导：交给一个完全不会的人，照着做也能完成。每项执行内容需补齐操作、材料、分支、示例与检查，不止于任务拆分。本版已按用户补充校准该定义。

## 从哪里读

问题诊断使用[目标与主要矛盾诊断](references/problem-diagnosis.md)：先确认目标，从资料提取信息要素并重新论证，找出最大堵点及其持续原因，形成一句话结论，并与用户共同补证。

本技能保持开放迭代，接受对话中的新方法及组会指导，按[方法更新机制](references/method-updates.md)吸收、检验并记录变更。

产地专题新增[事实驱动的场景方法](references/origin-scenes.md)，全流程增加[协作式追问](references/collaborative-inquiry.md)：先了解事实，再共同提炼、验证和修正想法，帮助用户提升判断能力。

电商任务新增[电商专题方法](references/ecommerce-report.md)与[电商内容最小单元](references/ecommerce-content.md)，覆盖完整报告、四类内容资产和执行材料。基于用户提供的电商参考案例提取方法，具体案例事实不作为通用基线。

先看[报告类型与进度路由](references/stage-routing.md)，自动识别总体、电商、产地、渠道或交易专题及当前进度。写作时采用[层层拆解与统一表达](references/writing-and-structure.md)，保留旧技能中有效的方法，按当前任务选择结构和深度。

* [SKILL.md](SKILL.md)：触发范围、核心规则和任务路由。
* [工作流](references/workflows.md)：诊断、定位、四专题、审查、结题和三年行动。
* [启动问询](references/project-intake.md)：项目背景、阶段、数据基线、修改意见和交付格式。
* [调研闭环与每日模板](references/fieldwork.md)：先本地后外地、主动追问、消费者访谈与问卷、录音复盘和固定日报。
* [十二章与十大工程](references/master-plan.md)：用户框架的完整覆盖。
* [四专题](references/special-reports.md)：供应链与交易中心、内容与生态电商、产地场景、渠道策略与运营。
* [评估案例](evals/cases.md)：未来迭代需要保持的行为。

1+4+1分别是总体报告、四份专题报告、结题或决策汇报。渠道报告可包含门店，也可采用其他渠道；是否开店取决于经营验证。

## 使用示例

将本目录作为技能包交给支持SKILL.md的环境，或先让助手读取SKILL.md。具体安装方式按使用环境处理。

首次使用保留整个目录，包括references与evals。告诉助手当前项目、要支持的决定、已有材料和本轮交付；尚不清楚问题时，可以从一次具体交易或经营经历开始。只准备访谈时，可直接要求生成按角色区分的提纲、追问分支、记录表与试访安排。

* 请使用品牌战略分析，对这些资料进行本地产业诊断，区分已证实约束与待验证解释，先给调研方案。
* 基于已确认定位，只制定渠道策略，比较经销、餐饮和电商，暂不做其他章节。
* 根据这些访谈与经营数据完成1+4+1，预算未知处保留参数，先提交总体判断再深化专题。
* 审查这份供应链方案，重点检查付费需求、单位经济、设施投资和参与者收益。

## 版本边界与后续完善

本版形成方法和输出约束，不能替代真实调研、经营数据、实际授权与专业核验。下一轮优先补充脱敏的真实案例：原始事实、当时选择、关键反证、执行结果及失败原因；据此校准定位判断、十大工程选择和各专题的启动条件。再增加不同模型下的结果比较，检验方法能否稳定保留你的判断。
