# 青岚鲜蔬教学材料

以下区域、人物、订单与数字全部为虚构材料，供方法练习，不可作为真实项目事实。材料截至教学时间6月15日。

## 委托

当地团队想通过区域品牌提高经营收益，拟建交易中心，同时准备开展一次餐饮试供。现有预算只允许先做小规模试办，金额需要根据测算再确定。希望一个没有调研经验的执行者明天能带着材料去访谈采购商，并把结果带回团队决定下一步。

## 访谈与记录

E001 合作社销售负责人说：菜很好，没人认识才卖不上价；只要统一包装、打一轮广告就行。没有提供客户拒购记录。
E002 餐饮采购甲说：上次约好8点到，10点才到，临时备料来不及。记录D01约定08:00、签收10:00。该单实际成交90元，10公斤。采购方说同规格产品也能从别处买到。
E003 生产者说：上次分级多花工时，最后按混装价格结算，以后不想做。未提供劳动时长；结算记录待补。
E004 供方发出10公斤装报价120元，但无接受或成交记录。现草稿J001写市场已经接受120元价格，并以120元测算试供收益。草稿P001据此建议建设交易中心。
E005 最近一次改包装同时打八折，订单从40单升到70单。客流、渠道变化和退款记录未提供。
E006 某企业出示一份检测合格报告，要求直接使用共同品牌。权利文件、产地证据和授权登记未提供。企业只在交易市场租了一个摊位。
E007 两篇地方资讯都称品牌曝光不足；第二篇注明转载第一篇，第一篇只引用E001销售负责人。

## 经营参数

拟试供为每单10公斤，客户是否接受100元/单尚待确认。为测算情景暂用净收入100元/单：货品60元、包材5元、配送12元、手续费3元；无其他变动成本的教学简化假设。预计120单/月，新增固定费用2000元/月；这些均为待验证预测，不是已经取得的业绩。备选情景配送17元/单。现有作业区可租用，新建规模及投入尚无论证。

## 公共安排

另一提案是由公共资金支持小规模质量信息服务，服务对象为本地符合条件的生产者，暂无向每位农户收费的安排。需求人数、有效职责、资金承诺和维护主体都待确认。

## 新材料到达时使用

采购甲补充：另一次D02准时到货，但仍退了一部分，因为大小不一致。退货数量及验收标准尚待核对。销售负责人确认E004仅为报价。
