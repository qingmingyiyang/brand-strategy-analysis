# 虚构冷链供货项目的周期材料

这套材料用于方法练习，单位为元；日期和经营安排均为虚构。无税费、退款、损耗、融资、受限资金或下述记录之外的其他收付。经营者为自营商。

1. 10月1日现金2000，已付款存货20件，每件成本50，无应收应付。
2. 10月2日采购80件，每件50，付款2000；其余2000于11月15日付款。
3. 10月20日交付并确认售出60件，每件100。10月25日到账3000，余下3000于11月10日到账。
4. 销售相关变动费用1200于10月28日支付。10月固定费用1800，其中既有设备当月折旧300，其余1500于10月31日支付。本期没有新购设备。11月只结清上述应收应付，没有新增业务或费用。
5. 未售货品完好；按50元单位成本保留，后续销售时间未知。
6. 用户只看到10月现金到账3000，就说收入是3000、采购4000全是本月成本，并希望按旺季一个月外推全年。他还准备建服务设施，报价只给建设费，运营和维修更新、退出价值、资金来源尚不清楚。

任务：复核10月经营结果、期末存货和欠款；按已知日期排融资前现金并承接11月；指出是否能直接推全年和投资回收。给普通执行者下一步应取得的记录及取数动作。
