# 战略选项的相邻条件练习

使用[原始材料](fixtures/strategy-options-input.md)完成本轮决定。执行者只取所需技能章节及原始材料；下列检查供独立评阅使用，单独运行时不要预先给执行者。

## 任务与交付

交一份包含进入路径比较、资源组合及阶段安排、品牌贡献验证的决策材料，并给出一个可供新人执行的下一动作。使用现有O/D/P/H/T对象，或在无需跨文件接续时用同样含义的简明记录。

## 观察重点

1. 同一组合内A计算一次，以既有服务范围成立为前提；增加范围先核容量。A+B为15万元、58人日，A+C为19万元、62人日，A+D为20万元、66人日；A+B+C为26万元、98人日，资金可容纳但人员超限。总量可容纳的组合仍需核对付款和排期。维持现状或仅取证也是可比较安排。
2. 能区分可接触客户、口头愿试、实际试供与续单。D的第125天履约与90天目标分别处理，后续成本及现金承接保留补证；B的长账期也可能改变路径选择。
3. 明确首个市场积累的分级、履约或客户能力，下一市场还要新增什么，并给继续、等待、调整条件。推荐有依据即可，不预设只能选择B。
4. 对旧推广材料先计算条件内变化：原表面成交率1.6%，新为1.2%，下降0.4个百分点、相对下降25%；成交数增加87.5%，单价增加20%，列示成交金额从3840元到8640元、增加125%。定义与退款未核对前，保留为材料中的表面计算；品牌单独贡献仍需辨别。
5. 品牌验证明确层级、变化与保持项、对象和分组、刺激版本及T口径，区分理解、选择和净收益。不同结果对应不同命名、背书、推广或兑现动作。
6. 下一动作包含对象、开场或操作、记录位置、核验材料和受阻办法；研究者承担专业判断。读取范围服务当前缺口。
7. 启用编号底稿时，沿用已有对象、数字编号及修订方式；方案名称与编号分别记录，重审条件回到相应D与T。简单正文的描述标签与程序消费的底稿编号分别识别。

## 改变一个条件再执行

1. 人日从80降为55，其他条件不变。
2. B全部客户要求70天账期，项目暂未取得新增资金。
3. 新推广活动恢复相同价格和包装，但访问仍有差异。
4. 试供记录证实分级已稳定，而现有可接触客户需求很少。
5. 首批试供成立，但新产季供给、异地履约和售后条件仍未取得。

分别观察建议、验证与资源安排是否随条件改变，以及哪些判断继续成立。保留独立输入、业务输出和读取记录，评阅结果写在包外项目工作目录。此练习用于模型行为走查；真人使用表现由实际执行另行观察。
