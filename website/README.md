# 品牌战略分析介绍页

以最小单元化、八项基石原则和多视角调研介绍 brand-strategy-analysis，再通过访谈、证据、定位与经营样例展示使用方式。页面与介绍影片共用浅绢纸、纸白、墨色与灰青绿，标题采用宋体，材料与正文采用无衬线。

首屏使用用户选定的纸质研究报告与山水稻田封面，完整显示图中文字，桌面和手机均保留16:9画幅。封面与影片共用`media/brand-overview/cover.png`，点击封面可以打开理念介绍视频，说明和主要动作排列在图下。样式、脚本与媒体URL带版本参数，便于已有页面读取本次资源。

## 本地运行

在仓库根目录运行：

```sh
python -m http.server 4387 --bind 127.0.0.1
```

打开 http://127.0.0.1:4387/website/ 。网页使用原生 HTML、CSS 与 JavaScript，无需安装前端依赖。静态托管时保留 website 与 media 的相对层级。

## 内容与交互

1. 最小单元示例说明动作、材料、顺序、分支、样例、检查与卡点处理，八项原则各有完整标题和说明。
2. 同一订单的三个角色陈述，展示事实、解释与立场如何分别核验。
3. 五个任务示例保留输入、研究动作和输出材料，支持点击和键盘切换。
4. 配送费用调整会重新计算单笔贡献与保本单量，使用教学假设。
5. 开始提示词、Git 命令与虚构访谈模板可直接复制或下载。
6. 介绍视频约2分49秒，围绕多方视角、事实核验、最小单元和八项原则展开，使用 media/brand-overview 中的成片和封面。

所有演示材料均为虚构项目。网页执行本地切换与核算，实际研究通过能够读取 SKILL.md 的 AI 助手开展。

设计与组件约定记录在 DESIGN.md。内容来自本仓库公共方法，介绍与呈现方式参考 https://peach.video/ 及其开源项目；网页代码为本次独立实现。
