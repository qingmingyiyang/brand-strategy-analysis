# 按需使用的交付契约

这些字段用于保证可交接；可合并成文字或已有表格，不要求每个任务生成整套空表。

| 对象 | 必要字段 |
|---|---|
| 任务简报 | 决策对象、受众、阶段、待决问题、材料、约束、交付形式 |
| 证据条目 | 主张、来源、时间地域口径、事实/陈述/推算/假设/目标、局限、影响的决定 |
| 核心假设 | 假设、成立理由、替代解释、可观察反证、验证动作、责任、决策影响 |
| 战略选项 | 人群场景、替代品、承诺、证明、能力、收益、投入、取舍、检验条件 |
| 工程卡 | 问题、目标、采用状态、经营主体、参与收益、资源、依赖、试点、验收 |
| 最小单元 | 要完成的具体结果、执行角色、开始条件、材料与取得方法、逐步操作、选择条件、可直接使用的模板或素材、成品示例、检查方法、异常与交接 |
| 年度计划 | 阶段结果、基线、指标定义、行动、负责人、预算依据、前置条件、里程碑、复盘 |
| 决策记录 | 已确认事实、选择及理由、未决项、适用范围、变更触发条件 |

## 最小单元的写作与验收

定义：交给一个完全不会的人，照着做也能完成。每个单元有明确结果，完成后能接到下一步；拆得更碎却仍不知道怎么做，不算达到标准。

1. 写明做完会得到什么，以及开始前必须取得什么材料、资源或权限。
2. 按操作顺序写动作，每一步说明使用哪个材料、做什么、记录到哪里。首次出现的专业词解释到能操作。
3. 有不同情况时，写成可观察的判断条件及对应动作；判断需要专业人员时，说明交给什么角色、提供什么材料、拿回什么结论。
4. 直接提供执行所需的访谈问题、话术、脚本、表格、内容或简报。占位符说明填什么、从哪里取得；不靠虚构事实补齐。
5. 给成品样例或完成状态，再给检查方法；检查失败时说明返回哪一步、修改什么或向谁求助。
6. 模拟零经验者从头照做，找到每处必须猜测或自行补设计的断点，补齐后再次走查。若缺真实资料导致暂时无法完成，明确断点与补齐动作，不宣称已经可独立执行。

### 示例：记录消费者最近一次购买

只有开展消费者访谈这一句话，读者仍需自行设计操作。可改写为以下单元：

- 结果：获得一条最近购买记录，用于识别实际选择标准；单条记录不代表整体市场。
- 准备：确认研究品类，将品类名填入下列问题；建立包含受访编号、购买时间、场景、产品规格、价格、渠道、比较对象、选择理由和原话的记录表。
- 开场话术：我们想了解你最近一次购买〔品类〕的过程，用于改进产品。你可以跳过不想回答的问题，现在方便聊一下吗？对方拒绝则结束；需要录音时先征得同意。
- 依次询问：最近一次什么时候买的？买来做什么？在哪买、买了什么规格、花了多少？当时还比较过什么？最后为什么选这个？哪些地方不满意？将回答填入对应字段，原话与自己的解释分栏。
- 分支：对方没有购买经历则标记无购买记录，另找有实际经历的人；记不清则写未回忆起，不替对方补答；出现好吃等笼统描述时追问具体哪个特点、与什么相比。
- 完成样例：购买时间＝受访者称上周，价格＝未回忆起，选择理由原话＝当天能送到。这只是格式示例，不是调研证据。
- 自查：是否记录真实一次购买；有没有诱导对方接受预设答案；未回答项是否标明；分析有没有超出原话。缺关键信息时，在对方愿意的前提下补问，否则保留缺口。

这个标准同样适用于定位分析和内容生成：分析应写清材料、推导和选择条件；内容方案应交付可用素材与操作说明。最小单元贯穿报告全过程。

## 经济性测算原则

先写业务流和资金流，再定义收入、变动成本、固定成本、资本投入与现金占用。说明含税口径、退款和费用是否已扣除，避免重复计算。统一单位、期间和服务边界；运营收入与交易总额分开。数据缺失时使用符号参数或清楚标记的情景，不将示例作为预算承诺。

## 行动完成的含义

交付文稿只代表完成设计。访谈、签约、试供、销售、建设和取得授权只有实际发生且有证据时才标记完成。待指定人员使用角色名并注明待确认，不虚构负责人的承诺。

统一执行与交接字段见[工作单元](work-units.md)；持续任务的证据编号、摘要和状态更新见[项目状态](project-state.md)。
