# 电商内容最小单元

使用顺序：消费者问题 → 四类内容资产 → 项目事实映射 → 选择优先项 → 生成执行素材 → 分发与交易承接 → 履约、真实反馈与复用。该方法用于写报告中的内容运营章节及执行包，不自动授权发布、联系达人或投放。

## 四类内容资产图谱

| 类别 | 用户需要回答的问题 | 可拆解方向 | 证据与边界 |
|---|---|---|---|
| 知识 | 是什么、有什么不同、怎样使用？ | 产地环境、文化、品种、感官特征、产品形态、场景、处理与保存 | 讲清可核验的产品事实；风土与品质因果需要证据，不能由地域名推导功效 |
| 证明 | 凭什么相信？ | 主体资质、产地溯源、过程记录、检验、可兑现服务、真实体验 | 证据匹配主张和具体产品批次；田间拍摄不能代替安全检验，用户体验不能证明治疗效果 |
| 情感 | 为什么与我的生活有关？ | 人物、地域记忆、家庭关系、生活方式、礼赠、开箱和参与感 | 来自真实经历或清楚标记的创意；不冒充消费者、虚构苦难、历史或神奇效果 |
| 交付 | 买到什么、怎么用、出问题怎么办？ | 规格、包装、时效、到货状态、使用卡、售后、复购服务 | 每个承诺对应操作能力、适用条件、责任与预算；不以极限承诺掩盖能力缺口 |

这是内容库的覆盖框架，不要求每个SKU都做四套宣传。优先处理影响购买和使用的关键问题。真实的人、真实产品、真实场景是素材来源原则；真实也可以发生在专业影棚或现代工厂，不等于必须泥地、老农、粗糙画面。

## 从通用图谱到项目素材

对每条候选填：资产ID、用户问题、产品/SKU、事实或素材来源、证据状态、消费者表达、内容类型、使用触点、优先级理由、负责人、待补材料。优先级根据决策影响、证据成熟度、产能和预算确定；重要却缺证据的内容先取证，不能直接发布。

逐级输出：内容大类 → 子模块 → 本地事实 → 核心信息 → 具体选题 → 可拍摄或排版脚本 → 执行检查。需要用户选择的策略先给选项及依据；已选定的内容直接细化，不停在方向建议。

## 每条内容的统一执行卡

| 字段 | 写到什么程度 |
|---|---|
| 目标 | 指定人群、场景、一个真实疑问和期望的下一动作 |
| 产品与主张 | 明确SKU、要表达的事实、证据位置、禁止超出证据的说法 |
| 开始条件 | 样品、标签、说明、素材、人物和拍摄授权、可用商品页；缺项说明找谁取得 |
| 角色与材料 | 谁拍、谁出镜、谁核对产品信息、谁接订单，器材和物料清单 |
| 脚本 | 按顺序写镜头、画面、动作、口播或正文、字幕与所需素材，时间长度按实际任务 |
| 承接 | 商品卡或已确认入口、规格价格、交付条件、客服答复和相关使用指导 |
| 检查 | 产品与文字一致，主张有据、人物与场景真实、声音和字可辨、入口可用、库存和承诺一致 |
| 分支 | 缺素材、产品信息冲突、无库存、没有拍摄许可时如何替换、补证或暂停相应动作 |
| 观察与复用 | 内容版本、触达与交易指标、观察期、用户问题、修改原因及可再次使用的素材 |

脚本中的占位符必须说明数据来源和填写人；关键事实未补齐时交付状态是待补证草稿。没有亲历者材料时用品牌介绍或采访提纲，不写成已经发生的买家日记。

## 示例单元 让新客知道一款佐餐产品如何搭配

以下是合成的操作示例，只演示方法。具体品牌任务应填入已确认产品事实，不借用案例的功效、认证、时效或人物故事。

1. **结果**：一条展示一次实际搭配的短视频及对应商品说明，帮助新客判断是否适合自己的用餐场景。
2. **准备**：运营员从商品资料取得SKU、规格、食用与保存说明及现有商品入口，填写核对表；取对应实物、标签、一份适用餐食、餐具、手机和稳定支架。只有标签或已核验说明支持即食时才采用直接搭配。
3. **事实检查**：产品负责人核对实物与资料。资料冲突先核验；产品需要加热或其他处理时按确认的使用说明演示，不自行编造温度、时间或安全保证。
4. **拍摄与台词**：先拍餐食与产品全貌，口播今天用〔产品全名〕搭配〔实际餐食〕；再拍规格标签，字幕〔已确认规格〕；按核验说明拍完整取用过程，口播这里展示一种搭配方式；最后拍完成状态，字幕保存和使用请按包装说明，并接已确认商品入口。口味评价只使用出镜者真实感受，不预写人人喜欢。
5. **剪辑检查**：依操作顺序排列镜头，删去遮挡、听不清或与实物不符的段落；核对字幕、SKU、入口及实际价格条件。使用必要字幕解释专业词。
6. **完成样例**：应包含产品和餐食识别、实物规格、连续操作、完成餐食和有效入口；这组可观察状态用于验收，不以保证爆单验收。
7. **异常处理**：没有可展示入口时交内容草稿并标待配置；未取得试吃者同意时改拍操作画面；没有核验保存说明时不生成保存天数。得到发布授权后才发布。
8. **复盘**：记录用户问不会用、规格不清或到货处理等具体问题；结合商品点击、订单和售后追查断点。下一版仅针对有依据的缺口修改，并保留版本。

## 图文、直播与交付的成套材料

图文提供标题、逐图信息、图片制作说明或实际素材、正文、证据引用和入口。直播提供开场、产品演示、使用场景、异议答复、真实优惠及库存条件、下单与履约提示、结束交接；直播结束后跟踪订单和售后，不只统计观看。

交付包按需要生成商品详情、客服问答、包装说明卡、食用或使用卡、售后流程和复购提醒。先对齐供给事实，再统一对外表达；不让内容团队承诺仓配团队无法完成的服务。

## 真实反馈与AI辅助

可邀请真实用户自愿分享，提供拍摄角度、问题和空白记录模板，让用户写自己的经历。不得预设好评、规定疗效结论、冒充买家或用水军形成伪口碑。奖励、合作与素材再使用先明确条件并核验当前规则，记录授权，商业合作如实说明；负面反馈进入产品改进。

AI用于整理已核验事实、拟选题、分镜、文案版本、字幕和设计草稿。为每次生成附资料白名单、允许主张、缺失项和审核人；工具按当前可用能力选择，不固定旧模型版本。生成场景、人物或示意图不能当作真实产地、检测或消费证据。

可用生成请求：根据以下已核验的SKU资料和素材，为〔人群〕在〔场景〕解决〔具体疑问〕。沿用执行卡生成脚本、所需素材、检查和异常处理。只使用所给事实；缺失内容列待补项；不虚构买家经历、认证、功效、优惠或服务能力。
