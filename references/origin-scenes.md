# 产地场景从事实走向设计

用于W5及产地场景报告审查。先读事实与用户想法，按[协作式追问](collaborative-inquiry.md)共同判断，再生成方案。案例提供书写逻辑和候选工具，不提供当地事实或必建项目。

## 事实优先于判断

先了解真实产地、生产生活、来访者和经营条件，再解释问题与生成想法。现有材料中的观点、宣传语和拟建设施不自动变成事实；用户陈述保留来源，必要时交叉核验。事实不足时可提出候选和补证计划，不宣布最终定位、唯一方案或投资回报。新事实与原判断冲突时，调整判断并说明改变了哪项前提。

最低事实清单按影响当前决定的程度逐步补齐：

| 事实领域 | 先了解什么 | 可追问的具体问题 |
|---|---|---|
| 产地与产品 | 真实地块、生产周期、产品特征和证明材料 | 哪些品质特点有样品、记录或检测支持？哪些只是当地惯常说法？ |
| 空间与使用 | 现有建筑、道路、水岸、权属和开放条件 | 哪些地方实际能使用？游客和生产作业会在哪相遇？ |
| 真实客源 | 来访来源、交通、季节、停留、付费和未成行原因 | 最近一批访客为什么来？实际做了什么、买了什么？ |
| 文化与人物 | 史料、口述、传说、真实技艺和愿意参与的人 | 这段故事来自哪里？讲述者愿意怎样参与和被呈现？ |
| 经营与社区 | 现有商户、农户意愿、服务能力、投入和收益 | 谁愿意经营、谁承担淡季成本？不愿参与的人顾虑什么？ |
| 资源与约束 | 时间、预算、接待能力、天气、生产与环境要求 | 当前最小能做成哪种体验？哪项条件尚未落实？ |

资料不全时优先现场观察、访谈和最小试办，不要求一次填完所有事实。分开已核验事实、来源陈述、推断、设计候选和待核验项，并为重要判断标来源。

## 十一个书写模块

完整报告按下列逻辑覆盖，沿用项目已有目录也可。模块深度服从事实和任务；不因存在章节就新增建设。

| 模块 | 核心问题 | 应交付的内容 |
|---|---|---|
| 一、背景与现状 | 本地实际有什么，问题在哪里？ | 资源和经营基线、客源证据、约束与未知 |
| 二、理念与定位 | 谁为什么值得来？ | 人群、需求、替代去处、可信差异、暂定主张及成立条件 |
| 三、核心场景 | 哪些真实资源适合转成体验？ | 候选比较、选择依据和逐项场景卡 |
| 四、动线与转化 | 怎样从抵达到参与、使用和购买？ | 实际空间距离、时间、容量、服务节点和退出路线；体验、消费与物流衔接 |
| 五、公共空间与识别 | 怎样让人找得到并方便使用？ | 导视、休憩、到达和社区共享设计，依实际场所安排 |
| 六、故事与传播 | 怎样让体验被理解和记住？ | 事实、传说与创作分层，人物和文化表达，真实素材生产 |
| 七、运营与主体 | 谁经营、怎样分工、各方为何参与？ | 运营、农户、商户和公共职责，报酬、责任、退出与四季经营 |
| 八、基础设施与支撑 | 哪些条件确实阻断接待？ | 按需补齐设施和专业核验，公共与经营投资分开 |
| 九、内容与电商连接 | 离开之后怎样继续了解与购买？ | 真实现场素材、产品与渠道入口、履约和自愿复购服务 |
| 十、财务测算 | 需求和收益能否覆盖投入？ | 客源及转化假设、收入成本、现金流、情景和敏感项 |
| 十一、实施与验证 | 先试什么，何时扩大？ | 最小体验试办、复盘、继续条件、分期资源与责任 |

## 场景生成与筛选

### 先说清什么是消费场景

消费场景在本方法中指：具体的人在某个时间、地点及关系中，为完成一种任务或获得一种体验，怎样接触、选择、使用产品及相关服务。先写谁、何时、与谁、为什么来、实际做什么、得到什么；再描述空间和活动。购买、使用和文化体验可以相连，也可以各有目标。消费者行为研究表明情境会影响选择，参见[Belk关于购买与消费情境的研究](https://journals.sagepub.com/doi/abs/10.1177/002224377401100206)；具体场景效果仍用本地记录核验。

一家店提供载体，店内可以承载多种场景；开店本身还没有交代场景机制。外摆提供空间条件，文化IP提供识别与联想，乐队和菜品比赛提供活动，实际价值由目标人群怎样参与及得到什么来说明。场景创新是对时间、关系、任务、动作或服务组合的有效改变，核验它相对原状态改善了什么。新颖本身不足以证明对区域品牌有用。

| 提议 | 先还原实际场景 | 有用与否怎样判断 |
|---|---|---|
| 增加外摆或炉子 | 下班结伴者是否确有空间、时段或用餐体验需要，怎样点单和体验产品 | 比较舒适与选择、排队、服务及经营结果，检查天气、管理和邻里影响；只写烟火气尚无解释 |
| 引入乐队 | 谁因什么原因在何时停留，音乐如何与品鉴、交谈或文化体验配合 | 体验与人群是否相符，能否记住品牌，是否影响交流和服务；热闹可有体验价值，成交贡献另验 |
| 举办新菜品比赛 | 厨师、采购者或消费者如何试吃、选择、采购及复现产地产品 | 菜品是否形成需求和后续采用，规格与供给能否兑现；奖项、人数与实际使用分别记录 |
| 打造大IP或新门店 | 哪种联想或服务使目标人愿意来、理解价值并在需要时选择 | 核验品牌关联、到访理由、理解与持续经营；标识上线及开门各是过程记录 |

热卤、现烤、外摆等具体做法按人群、需求、产品关联、增量效果与全周期经济性比较。某企业做过、研究者喜欢或不喜欢，都先作线索；宣称有效或无效要取得对应店型、时期、原状态、执行与结果资料。既有门店基线足够时直接复用。

### 把产地与品牌强绑定

核心构成是让真实产地成为品牌价值的可感知证据：产地的自然或生产条件、技艺、产品和生活怎样形成特色，访客怎样亲历，并能正确说出这个品牌与该产地的关系。真实资源 → 可观察证据 → 参与动作 → 价值理解 → 品牌与产地记忆 → 体验及后续选择，逐环设计。搬到另一地仍完全相同的通用布景，需继续解释为何属于本品牌。

竞争壁垒是需要证明的结果。问哪些资源或协同难以复制、游客是否在意、经营者能否持续兑现、对手还有什么替代方法、维护这些能力花什么成本。地理独特不自动成为购买理由；强绑定通过真实品质、体验、共同服务和声誉积累才可能提高替代成本。产地体验、交易地与产品原产地分别标明。

给普通执行者一个小单元：先约一类实际访客，在获准开放的现有场所，围绕一种可验证特征办一次体验。备一张产地事实卡、一段中性讲解、一个观察或参与动作和一个自愿体验/购买出口。先请访客复述最记得什么、还记得哪些名称及依据，不提供品牌或产地名字；再追问看到或做了什么、怎样理解产品与产地的关系、怎样影响体验或选择。需要提示名称或选项时，提示后回答另栏记录。保留问句、测量时点、原话和误解，再决定是否改讲解、产品或动线。

无提示记忆、提示后辨认与听完解释的理解是不同结果。对比不同场次或前后状态时，问法、时点与提示条件保持可比，不能用提示后的正确回答替代自然记住。样本来自哪些访客及场次同时记录，单次回访不推断所有人的认知。

虚构设计例：围绕某产地水草管理与蟹的养殖事实，展示当批生产记录和实际观察，说明已核验的作用，再按控制条件品鉴。技艺与口味因果尚未证明时分别呈现，不把一次品鉴写成普遍领先。若访客只记住活动却记不住产品与产地关系，补证和调整关联；若记住但没有购买，也继续问用途、价格与履约，体验价值与成交分别评价。

### 用一次试办验证创新

先选当前目标，例如改善体验、形成正确品牌记忆、增加有效采购或改善单场收益；其余指标作解释材料。写原状态、拟改变的一个关键点、成立机制、观察周期、可比条件和继续/调整/停止条件，按下方试办动作实施。记录原状态及试办的到访、参与、体验、品牌关联、购买与复购对应分母，核对人员、物料、损耗、服务和淡旺季成本。存在促销、天气和客源同时改变时分开核验。

交付场景卡、现场脚本、记录表和一页复盘。成功指标从项目基线与目标设定；符合体验目标的改进可以保留，涉及商业扩张再核算持续需求、利润与现金。关键机制未成立时调整，不因已经做出空间或办过活动就扩大。

按真实资源 → 游客疑问或需求 → 可观察证据 → 参与动作 → 产品价值理解 → 消费或其他体验结果 → 经营条件逐项推导。不能从稻田直接跳到博物馆、民宿和大型演艺。

产地观摩、品鉴餐饮、文化展示、手作研学、演艺、住宿、检测科普都是候选模块。每个候选比较顾客需要、事实基础、可运营性、投资与持续成本、生产干扰、社区意愿及低成本替代。既有空间、预约体验、临时展示或合作经营可先验证需求。

五感是体验检查工具。视觉看见什么、听觉听到什么、触觉操作什么、嗅觉与味觉如何真实发生，均与产品和现场相符。无需每个场景配齐五感，不用人工氛围冒充生产或品质证明。

对比品鉴记录样品来源、批次、存储、烹饪、呈现顺序和提问，按比较目的控制条件。少数体验不能证明普遍品质领先。科普互动和正式检测分清，示范数据标示范，不能伪装实时监测；文化展陈不把传说改写成史实。

## 每个场景的统一设计卡

依次写：事实来源与未决项、目标访客、要解决的问题、核心体验、实际位置与动线、所需资源、执行主体及收益、游客操作、服务脚本、商品或内容衔接、成本与容量、检查和异常处理。每一项继续拆到零经验者可执行，不能停在统一培训、做好接待等概念。

最小试办示例：在已具备接待条件的现有场所办一场预约品鉴。

1. 确认允许开放的场地、实际承办者、可用产品和使用说明，取得已落实的接待与食品操作安排。条件不具备时先补齐，不能靠文案宣称安全。
2. 按实际空间和服务能力确定预约容量、场次及天气替代安排。预约说明写时间、地点、费用与包含内容、取消办法和联系角色，不保证到访或成交。
3. 提前备好产品核对表、原始证据或说明卡、器具、动线图、讲解稿、反馈表和可用购买入口。
4. 接待时说明今天观察和体验什么，按核验资料讲解；分发样品并依确认的操作说明引导。记录参与者自己的感受，不引导必须认为本产品更好。
5. 愿意购买者查看实物规格、价格和交付安排；其他人可自由结束体验。反馈询问最有印象之处、没弄明白之处、是否愿意再次参与及原因。
6. 核对实际到访、耗时、成本、服务问题与成交，完成一页复盘。资料不符暂停相应讲解，场地或天气不适用则执行已告知的替代或取消方案。

涉及水岸、高处、演出、住宿、儿童、生产作业等活动时，按具体方案取得相关专业评估与必要手续，写清责任及开放条件。参考材料中的宽度、高度、无护栏、用水、容量等描述不能直接成为施工或运营指令。

## 经营与扩展判断

区分访客量、付费人数、交易额、运营商分成与净现金流，避免把商户总流水计入运营商收入后再次计分成。按客源、营业日、容量、转化、价格和季节推导收入，列人员、物料、能源、维护、渠道、损耗、固定投入及营运资金。

回收期说明计算方式、投入节奏、淡旺季、爬坡与现金流，区分运营盈亏平衡和收回投资。证据不足时给参数情景，不冠以最可能；客源与运营尚未验证时优先试办。

与其他专题协同：电商承接真实内容和离场订单，渠道承接团体或采购客户，供应链承担打包寄送。共用设施、人员和预算只计一次。品牌承诺保持一致，场景报告中新出现的品种、品质和文化定位需要回到总体基线核对。


## 三种可选择的体验设计工具

1. 空间叙事：现有道路和接待条件适合时，用一条主线串接少量节点，每个节点回答一个访客疑问。画实际距离、耗时、容量、出口与替代路线，试走检查能否理解产品价值；不要求所有产地建街区或栈道。
2. 分时感官：依据真实生产、季节和运营安排，比较不同时段的可见、可听、可尝内容。测试停留、回访意愿及新增运营成本，避免为了凑晨午晚体验制造不真实的生产场景。
3. 参与角色：从观察、动手到理解与自愿持续参与，设计访客能完成的任务和反馈。身份名称、纪念物或认养仅为可选工具，消费与参与分开，不能把角色升级等同于必然转化。

三种工具可单独使用。场景模块、维护预算及篇幅来自需求、现场、人员和收入成本；历史案例中的固定五场景、固定投资比例与章节页数不作为通用标准。
