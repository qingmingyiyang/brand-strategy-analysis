# 按任务选择工作流

本文件只在需要理解行动顺序、流程依赖或审查覆盖时查用；业务方法按阶段路由选定后可直接执行。每次只展开实际需要的路径。输出深度由决策、证据和资源决定。资料不足时交阶段性判断与补证行动，不伪装成完成全部调研。

下列流程是导航，不是最终执行说明。实际生成报告时，每个步骤都按最小单元标准展开，使完全不会的人能根据材料、操作、分支、示例和检查完成。不能将导航中的研究、设计、验证等词原样当作已完成的执行方案。

<a id="w0"></a>
## W0 总体规划与1+4+1

确认委托边界和受众 → W1行业与本地诊断 → W2定位与目标 → 按十二章规划能力、产品、认知、机制和主体 → 筛选十大工程 → 对选中工程调用W3至W6 → W9排资源和行动 → W7检验一致性 → 按委托W8形成决策汇报。

交付保持总体报告、专题与结题汇报各自职责。选题未成立的专题可交不建设的论证或条件性方案；不得用六份报告数量替代决策价值。

跨区域统筹、品牌组合与企业生态设计按[战略统筹](strategic-perspective.md)核验共同认知、地方差异、经营主体和资源分配。年度回顾转向下一阶段规划时，明确已有事实支持什么长期能力建设，不将年度工程数量作为战略本身。

<a id="w1"></a>
## W1 研究与诊断

输入任务目标、已有资料和产业链线索。研究顺序为：已有事实或桌面研究 → 初步诊断或探索问题 → 本地取证 → 外地比较 → 回到本地核验 → 修订判断与下一轮。

调研操作、提纲、录音与日报使用[调研闭环](fieldwork.md)，诊断推导使用[目标与主要矛盾诊断](problem-diagnosis.md)。解释尚不清楚时，先准备开放提纲，从具体事件取得事实。外地比较以本地发现为线索，对齐竞争条件，再核验差异是否真实、顾客是否在意及是否能稳定兑现。

输出与本轮研究阶段相符：探索阶段交线索和下一提纲；诊断阶段交一句话结论、目标与边界、机制、堵点、矛盾、替代解释及后续取证。

<a id="w2"></a>
## W2 定位与价值论证

输入：诊断、目标人群、实际替代品、可兑现能力和约束。

按人群与场景生成有实质差异的方向 → 对每个方向说明需求、当前替代、承诺、证明、能力差距、参与者收益 → 比较消费者价值、相对竞争力、兑现成本和战略取舍 → 选定或安排试验 → 提炼定位语及视觉简报 → 设阶段目标。

输出包括谁在何场景因何证据选择本品牌，以及暂缓的人群、产品和渠道。口号无法替代论证；独特资源未必是购买理由。

价值语按消费者所得、相对差异、理解记忆与兑现证明检验；文化认知借用及区域命名安排参见[战略统筹](strategic-perspective.md)，不把记忆度等同于购买或健康功效证据。

<a id="w3"></a>
## W3 供应链与交易

追踪当前订单和费用 → 找出服务需求与付费方 → 比较运营方案 → 建单位经济和最低业务量模型 → 设计最小交易流程与责任 → 试点 → 依据结果决定设施与扩张。输出参照四份专题文件。

<a id="w4"></a>
## W4 内容与生态电商

选择人群场景与产品 → 明确内容证明和购买入口 → 连接订单、仓配、售后 → 核算贡献利润及现金需求 → 交付可执行内容与履约包 → 试验与复盘。流量增长与经营成立分别判断。

完整报告或机制深化读取[电商专题方法](ecommerce-report.md)，按九章覆盖研究、组织、选品、内容、交易及支撑。进入内容创作时读取[电商内容最小单元](ecommerce-content.md)，从知识、证明、情感、交付资产逐级写到可直接执行的素材。已有稿件先按其阶段与修改范围处理，不重做全部九章。

<a id="w5"></a>
## W5 产地场景

研究到访需求与客源 → 设计体验到购买旅程 → 复用本地产地资源 → 明确运营者、容量与收益 → 试办最小体验 → 决定设施投资与常态经营。缺少稳定客源时先验证客源。

产地场景以[专用方法](origin-scenes.md)为主。用户想法难以提炼或确需带练时，再补[协作式追问](collaborative-inquiry.md)。先还原现场事实与用户想法，再比较场景候选；关键节点邀请用户说明依据和取舍，试办后共同复盘。参考案例中的场景、尺寸、投资和故事均需按本地事实重新判断。

<a id="w6"></a>
## W6 渠道策略

按场景筛选渠道 → 比较采购标准、利润与账期 → 定产品和交易政策 → 设计试供与动销动作 → 验证复购、回款和各方收益 → 扩展有效渠道。开店另做单店经济核算。

<a id="w7"></a>
## W7 审查与修改

先明确用户要审查还是直接修改，再按委托选择检查项：论证检查证据和推导，经营设计检查市场、消费者、激励和经济性，执行方案检查责任资源与失败条件，多专题整合检查一致性。纯措辞修改沿用已确认的判断与数据。复用有效趋势基线；变化未知或只靠通用趋势词支持方案时，再取[市场趋势方法](market-trends.md)核验。对关键策略提出最有力的反对解释，并用同一证据标准检验。

输出问题、依据、影响和最小修正；已授权修改时直接修改相应范围并说明剩余缺口。预演失败用于改进方案，不编造风险概率。

<a id="w8"></a>
## W8 结题与决策汇报

输入总体报告、专题结论、听众职责及待决事项。按需要组织：为什么值得关注 → 本地价值或经营缺口 → 形成缺口的机制 → 可行机会与选择 → 如何经营和兑现 → 资源、责任、阶段目标 → 请求决策与未决条件。

每一步需有对应证据；缺少本地机会时如实给条件性结论。区分过去成效、当前动作与未来计划。结题汇报重新组织核心论证，不拼接六份目录，不自动附品牌资产估值。

<a id="w9"></a>
## W9 行动与持续验证

从目标反推可观测结果 → 明确能力和前置依赖 → 安排试点与资源 → 按实际周期排三年阶段 → 指定负责角色与验收 → 设置复盘和调整条件。

输出年度行动表和近期可启动任务。经营指标与公共目标分别设置；指标要能影响下一步决策。对未知预算给参数和测算方法，避免假精确。
