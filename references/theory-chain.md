# 从消费者选择到产业行动的理论支撑链

在设计研究、解释产业堵点、论证品牌定位或设计经营机制时，按实际问题读取本文件的对应模块。理论用于提出可检验解释，不是既定结论，也不是每份报告必须填写的章节。默认本地线索先行，理论帮助追问；若材料不支持，应修正解释。

## 选择入口

| 当前问题 | 优先模块 | 下游成果 |
|---|---|---|
| 消费者为何买或不买 | JTBD顾客任务 | 场景、选择理由、替代品与大单品假设 |
| 产品不错但品牌作用不清 | CBBE品牌认知；信息不对称 | 认知缺口与价值证明方案 |
| 产业增长或收益受阻 | 产业组织与SCP；五力 | 关键堵点、价值分配与主要矛盾 |
| 主体难以合作或持续投入 | 交易成本；共同治理 | 合同、组织、参与收益与监督设计 |
| 产业升级如何整体推进 | 食品价值链；必要时集群与钻石模型 | 升级路径、分阶段试点与行动 |

这是一条相互检验的分析链，不是固定执行顺序。购买需求检验产业方案，供给与治理条件也检验品牌承诺。理论解释机制，框架组织分析，访谈、问卷、选择研究和实验负责取得证据；不能混称为同一种理论。

## 统一证据卡

每次实际使用记录：研究决定、候选机制、支持证据编号、反证或替代解释、缺口、取证对象、具体问句、所需材料、答案对判断的影响、下一步。复用[项目摘要与证据交接](project-state.md)，不重复建账。以下问句直接放入对应主体的提纲，再按品类和场景改写。

## 1. 消费者为什么买：JTBD

- 机制：人们在特定情境中选择产品以取得某种进展，功能、社会与情感因素可能共同影响选择。不要事先认定三类因素都重要。
- 触发：已有产品优势，但说不清谁在何时因何选择；画像只有年龄与收入。
- 依次问：最近一次何时购买？当时要解决什么事情？此前怎么解决？比较了哪些选择？何时决定购买？谁参与决定或实际使用？哪件事让你犹豫？使用后是否达到预期？
- 证据：具体购买时间线、实际替代选择、支付与使用记录、放弃或更换经历；陈述与实际行为分开。
- 反证：口头说重视某特点却持续选择不具备它的产品，需检查价格、可得性、他人决策等解释；不能据此直接认定受访者说谎。
- 输出：情境—任务—现有方案—转换阻力—可兑现改善表，交给细分与定位单元。访谈发现的场景只作为候选，不直接推算总体占比。
- 来源：[Christensen Institute](https://www.christenseninstitute.org/theory/jobs-to-be-done/)。

## 2. 品牌凭什么被认可：CBBE与信息不对称

### CBBE顾客基础品牌资产

- 机制：品牌知识会影响消费者对营销的反应；重点研究知名度和品牌联想的强度、积极性与独特性。它不等同于财务品牌估值。
- 问句顺序：买〔品类〕时首先想到哪些品牌或产地？随后才提示本地品牌：是否听过？想到什么？从哪里形成印象？与哪些品牌相似或不同？这些印象影响过哪一次选择？
- 证据：无提示认知、提示认知、消费者原词、信息来源及购买记录；先无提示后提示，避免提前展示口号污染回答。
- 反证：认知高但不购买，转查需求、价格、渠道与履约；不由认知低自动推出传播是最大堵点。
- 输出：认知现状—期望联想—现有证明—缺口—验证动作，交认知与内容规划。比较有品牌与无品牌反应时控制产品及展示条件，不把简单组间差异直接解释为品牌因果效应。
- 来源：[Keller 1993原始论文](https://journals.sagepub.com/doi/10.1177/002224299305700101)。

### 信息不对称与质量识别

- 机制：买方难以识别品质时，优质供给可能难以获得相应回报。这是待检验解释，产品差异不明显或需求不足也是候选原因。
- 问：收货前怎样判断品质？最信什么证据？上次判断失误是什么？同规格品质好坏实际价差多少？退换和复购如何变化？
- 证据：可比批次、质量与订单记录、展示信息、投诉与退货原因。检测指标本身不证明消费者愿意付费。
- 输出：难识别的属性、有效证明、验证成本与提供者。可比较不同证据展示的真实交易反应，不能假设贴标或追溯一定有效。
- 来源：[Akerlof关于信息不对称的说明](https://www.nobelprize.org/prizes/economic-sciences/2001/akerlof/article/)。

## 3. 产业价值如何创造与分配：产业组织

SCP是结构—行为—绩效的分析框架；产业组织还涉及主体策略、信息与激励。调查可从目标与绩效缺口反向追查行为和结构。分析时考虑反馈关系与其他因素，不把S→C→P视为已经证实的单向因果。

| 层次 | 操作与问句 | 所需证据 |
|---|---|---|
| 绩效P | 要提升产值、增加值、利润还是农户收益？差距在哪个环节？ | 指标定义、基线、收入成本、损耗与现金回收；避免交易额和增加值混算 |
| 行为C | 最近一次如何采购、定级、定价、签约？过去哪项投入未持续？ | 订单、合同、定价与分级记录、投资和退出事件 |
| 结构S | 谁控制客户入口？能换买家吗？进入和退出需要什么？ | 在明确产品地域期间内的主体分布、市场份额、渠道替换成本和进入条件 |

五力作为补充检查竞争者、买方、供应方、新进入者及满足相同需求的替代选择。不要只研究本品类头部品牌。企业少或集中度高不能单独证明竞争弱，也不能直接推出应合并企业或限制进入。

将关键堵点表述为机制：〔结构条件〕影响〔主体行为〕，导致〔目标差距〕；并写竞争解释与验证条件。按[问题诊断](problem-diagnosis.md)比较影响，形成主要问题和主要矛盾，不只罗列三张现状表。

来源：[FAO农业政策中的SCP](https://www.fao.org/4/w7415e/w7415e0f.htm)、[诺奖产业组织背景](https://www.nobelprize.org/uploads/2018/06/advanced-economicsciences2014.pdf)、[哈佛五力](https://www.isc.hbs.edu/strategy/business-strategy/Pages/the-five-forces.aspx)、[世界银行关于集中度的限制](https://blogs.worldbank.org/en/allaboutfinance/measuring-bank-competition-how-should-we-do-it)。银行研究用于说明方法限制，不作为本地农产品竞争的证据。

## 4. 主体为什么愿意合作：交易成本与共同治理

### 交易成本经济学

- 触发：找货、验货、监督、履约或争议处理成本高，考虑设平台、合作社或自建体系。
- 问：最近一笔交易花多久找人和验货？谁承担不合格、毁约和延迟损失？哪些投入只能服务该买家？换伙伴损失什么？过去合作在哪里中断？
- 比较：市场采购、长期合同、合作组织、内部运营等实际可行方案；逐项比较生产成本、协调监督成本、专用投入、风险和执行能力。不能因市场交易有成本就默认全部自建更好。
- 输出：治理方式比较表与小范围试行安排，交交易中心、渠道和企业生态设计。
- 来源：[Williamson原始访谈](https://www.nobelprize.org/prizes/economic-sciences/2009/ostrom/164465-ostrom-williamson-interview-transcript/)。

### 集体行动与共同治理

- 触发：区域声誉共享、质量维护或推广需要多人投入，但有人不愿付费或搭便车。
- 问：谁制定规则？谁享受收益、支付成本？谁有监督能力？违规怎样被发现和处理？意见不同如何申诉？退出后有什么影响？
- 证据：实际参与、费用与服务、监督记录、违规处置和退出案例；口头支持不等同于持续参与。
- 输出：参与边界、收益成本、监督、争议与调整机制，并验证主体是否接受和有能力执行。区域品牌并不等同于自然公共池资源，仅借鉴共同治理问题意识；具体授权与法律安排需另按适用事实核验。
- 来源：[Ostrom与Williamson诺奖说明](https://www.nobelprize.org/uploads/2018/06/popular-economicsciences2009.pdf)。

## 5. 怎样推动升级：食品价值链与验证

FAO可持续食品价值链框架关注生产、聚集、加工、分销及其治理联系，从经济、社会和环境结果分析相互关联的根因。适用于农产品整体诊断与升级设计；多目标取舍仍需用户确认。

1. 画真实货物流、资金流、信息流与责任关系，标明每个环节的实际主体，缺失主体注明待核验。
2. 收集各环节收入、成本、损耗、账期、能力和风险，问：最近哪次有需求却无法接单？谁被卡住？上下游怎样受影响？
3. 找决定性约束及持续原因，判断改变后谁获益、谁增加负担、谁可能退出。局部成本下降若转嫁给别的主体，不直接记作整体效率提高。
4. 比较升级方案，从可小规模检验的交易或流程开始，记录假设、基线、投入、观察周期、指标、继续或调整条件及负责人。期限和阈值依据业务事实确定。
5. 更新诊断与项目摘要，再进入三年计划；试点成功的条件与扩张限制一起交接。

来源：[FAO框架](https://www.fao.org/sustainable-food-value-chains/what-is-it/en/)、[2024方法简报](https://www.fao.org/sustainable-food-value-chains/library/details/en/c/1676564/)。[机会解决方案树](https://www.producttalk.org/2016/08/opportunity-solution-tree/)可连接目标、问题、方案和验证，但区域公共目标不能硬压成一个GMV指标。

需要解释本地能力网络时，再用集群与钻石模型检查需求、要素、相关产业和企业竞争之间的联系，收集专业服务、人才、技术扩散和真实协作证据。不能把园区建设等同于形成集群。来源：[集群研究](https://www.isc.hbs.edu/competitiveness-economic-development/research-and-applications/Pages/cluster-studies.aspx)、[钻石模型](https://www.isc.hbs.edu/competitiveness-economic-development/frameworks-and-key-concepts/Pages/the-diamond-model.aspx)。

## 调研工具如何选

| 要回答的问题 | 选择与执行条件 | 结论边界 |
|---|---|---|
| 为什么发生或如何决策 | 事件访谈、观察、记录回查；加入反例对象 | 发现机制，不据少量访谈估总体比例 |
| 某类现象分布如何 | 定义总体、招募与抽样、问卷预测试；报告样本与未覆盖人群 | 便利样本不能自动代表全国，扩大数量不能消除选择偏差 |
| 属性和价格如何取舍 | 有研究设计能力时使用联合分析；先定属性水平与现实组合，预测试并检验模型 | 选择任务不等于真实销量；不凭几个评分题宣称完成联合分析 |
| 某价格是否可接受 | 价格敏感度问卷作为探索，结合成本和实际成交验证 | 接受区间不等于利润最优价；不照搬软件订阅定价规则 |
| 方案是否有效 | 真实试供、试销或适当实验；控制可比条件，预先定义观察与停止规则 | 前后变化可能受季节和客户构成影响；小样本不制造统计确定性 |

调查质量参考[AAPOR](https://aapor.org/standards-and-ethics/best-practices/)；联合分析工具说明参考[选择型联合分析](https://info.sawtoothsoftware.com/help/discover/survey-elements/cbc/creating-a-cbc)。工具商说明只用于解释方法，不视为效果背书。

## 最小单元示例：核验分级投入为什么没有持续

此例是方法演示，不是任何产地的事实。

- 准备：建立表格，列主体编号、批次日期、品种规格、质量等级、数量、成交价、分级成本承担者、额外成本、付款条件、来源编号、缺失项。先取得授权可用的订单和分级记录；商业敏感信息仅保留完成研究所需部分。
- 找对象：从本地线索中分别联系做过分级后停止、仍持续分级的生产者，以及对应收购方；无法取得某类对象则注明缺口，不用推测补齐。
- 依次问：最近哪批分级？如何判级？谁付人工或检测费？各等级实际卖多少？是否同时间同规格？停做发生在哪次？如果更换买家会怎样？将回答与记录对应，无法验证的标来源陈述。
- 分支：若存在价差，比较是否覆盖额外成本及账期影响；若无价差，问收购方是否能识别、是否有下游需求；若持续分级者能获益，比较合同、渠道和品质条件。
- 成品示例：J001暂定为分级回报不足；支持E001订单与E002成本记录；反证E003另一渠道存在价差；待核验为该渠道是否可进入。示例编号需替换为真实索引。
- 验收：对比是否可比、成本是否漏项、同源证据是否重复计数、替代解释是否检验。若只有一方口述，结论保持假设并交付对方核验问句。
- 交接：将支持条件、反例与缺口传给合同或渠道设计单元，再确定是否试行分级定价。不要直接宣布需要建设交易中心。

本文件是基于公开资料的项目适应化设计。理论不能证明具体项目判断；实际有效性需用项目证据与实践持续检验。
