# 报告类型与进度路由

这是任务到主方法的唯一清单。先判断本轮交付及当前缺口，再选对应方法；报告类型仅在确实要出报告时识别。文件名和关键词用于找线索，正文、材料及用户当前要求决定范围。

## 按当前进度选择方法

先读取匹配的一项主方法。表中补充条件发生后才取补充方法；多个独立交付逐项推进。已读且未变化直接复用。一个方法内的引用是进一步查用入口，不是需要递归读取的依赖树。

| 本轮交付及缺口 | 主方法或章节 | 何时再补充 |
|---|---|---|
| 背景、目标或范围实质不清 | [启动问询](project-intake.md) | 已有信息足够时直接选下列任务，不经过本项 |
| 准备提纲、问卷、安排下一步取证、多人调研或外地比较 | [调研闭环](fieldwork.md)相关部分 | 某个因果或证据判断仍有缺口时补推理方法；先可探索取证 |
| 提取专家在具体事件中的判断依据与经验 | [关键决策法](fieldwork.md#用关键决策法还原专家判断) | 需要把判断教给新人时再取协作式追问的转折带练；普通现况访谈沿原提纲进行 |
| 录音整理、调研日报、批量编码 | [调研闭环](fieldwork.md)录音、日报或编码本 | 角色利益与信息范围难以区分时补[多角色核验](independent-field-judgment.md) |
| 核验真问题、诊断堵点或比较赛道成败 | [问题诊断](problem-diagnosis.md)对应部分 | 证据或因果仍不足时补推理；具体机制解释需要理论时再补理论链 |
| 研究趋势，核验方案是否适应市场变化 | [市场趋势与战略适配](market-trends.md)对应单元 | 已有有效基线直接复用；实际收益或投资判断才补经济方法 |
| 核验论证前提、推导或比较解释 | [推理与证据](reasoning-and-evidence.md#逻辑思维怎样进入研究)相关部分 | 简单已知推导直接完成；需要具体因果评估再补相应验证 |
| 比较定位、区分点与大单品，提炼价值语 | [价值主张与证据](value-claims-and-evidence.md) | 趋势未知或适配证据不足时补市场趋势；需主体统筹时补战略统筹，成本影响取舍时补经济方法 |
| 选择先进入的客群、市场及下一阶段 | [进入路径比较](strategic-perspective.md#比较进入路径并确定先后) | 收益或资金影响次序时补对应核算；已有定位直接复用 |
| 多项工程竞争同一预算、人手或容量 | [资源组合取舍](strategic-perspective.md#在资源约束下选择工程组合) | 单项试办资格有缺口时补投入关卡；实际重复测算时再用经济工具 |
| 辨别品牌自身贡献并决定命名、背书或传播投入 | [品牌贡献验证](value-claims-and-evidence.md#验证哪一层品牌带来了什么贡献) | 新的因果设计超出现有材料时补推理方法；净收益取舍才补经济核算 |
| 品牌价值评价、年度变化比较或价值发布 | [品牌价值评价](brand-value-evaluation.md)对应单元 | 八维按项目选择；已有口径与事实直接复用，归因不清才补推理，重新算收益才补经济方法 |
| 完整总体规划的结构与覆盖 | [十二章与十大工程](master-plan.md) | 当前章的具体研究或专题设计从本表选方法，逐章推进；流程依赖不明才查[工作流](workflows.md#w0) |
| 电商专题研究、结构或经营机制 | [电商报告](ecommerce-report.md) | 要写可执行素材时转[电商内容](ecommerce-content.md)；物流缺口只补该环节 |
| 消费场景定义、创新筛选或产地场景试办 | [产地场景](origin-scenes.md#场景生成与筛选)及本轮相关部分 | 已有明确场景直接展开；实际投资判断再补投入方法 |
| 供应链或交易服务设计 | [专题方法的供应链部分](special-reports.md#供应链与交易中心) | 需完整经营核算或设施选择时补相应经济方法 |
| 渠道、试供、动销或门店经营 | [专题方法的渠道部分](special-reports.md#渠道策略与运营) | 按本轮单店、线路或交易经济问题补核算 |
| 跨区域统筹、品牌组合、企业生态与年度建议 | [战略统筹](strategic-perspective.md)相关部分 | 要交申请操作、质量记录或投入条件时补共同治理单元 |
| 人才等政策的条款、金额与办理材料 | [政策条款单元](strategic-perspective.md#把政策读成可以办理的条款) | 先查项目地区当期原文与附件；实际财政和垫资测算再补经济方法 |
| 先进入者控制、进入限制及收益机制 | [产业组织中的控制机制](theory-chain.md#先进入者如何取得并保持控制收益) | 先核具体市场和控制点；实际收益测算或权利争议再补相应方法及专业依据 |
| 已有研究判断，需转经营流程、工程或试办设计 | [研究到经营设计](research-to-operation.md) | 具体操作、数字或治理缺口发生时再补对应单元 |
| 品牌承诺兑现、申请授权、质量共管或投入条件 | [品牌经营](brand-operating-manual.md)对应单元 | 具体收益或投资结论需要核算时补相应经济方法 |
| 算利润、保本量、周期成本、现金是否够用 | [经营与现金核算](economic-accounting.md) | 长期设施及投资回收再补投资经济性；无经济决定时复用已有基线 |
| 设施投资、回收、运维更新或财政负担 | [投资与公共投入](investment-economics.md) | 基础营业与现金归属不明时补经营核算；需求/运营/试办资格不明时补投入条件 |
| 主体参与收益、价差或观察指标 | [收益价差与指标](economics-and-metrics.md)对应单元 | 要重新核算净收益时补经营核算；采用现成已核定数据时直接定义指标 |
| 写章节、润色、逐页内容、结题表达 | [统一表达](writing-and-structure.md)对应部分 | 修改实质判断或设计才补该主题方法；已有正确内容直接复用 |
| 审查已有稿件或整理修改意见 | [审查工作流](workflows.md#w7) | 已授权修改时只补实际发现的领域缺口；纯措辞问题转统一表达 |
| 年度行动、执行交接或操作包验收 | [交付契约](output-contracts.md)相关部分 | 资源依赖和行动顺序不清才查W9；独立委派与责任交接时补工作单元 |
| 连续项目摘要、证据失效及更正传播 | [项目状态](project-state.md) | 字段、编号和关系不明时补[决策底稿](decision-model.md)；多报告定位旧引用时按该方法使用显式文件检查 |
| 多材料的证据与决策关系建模 | [决策底稿](decision-model.md) | 有实际项目接续问题才补项目状态，普通分析可用现有记录 |
| 用户需要理解基础、聚焦或边做边学 | [协作式追问](collaborative-inquiry.md)相关部分 | 能理解并运用时返回当前业务单元，已有能力直接复用 |
| 理论解释当前机制确有缺口 | [理论链](theory-chain.md)选择入口及相关单元 | 从问句、证据与反证落到动作；普通诊断不默认加载整套理论 |
| 查用户项目的历史经验 | [私人案例方法](private-case-library.md) | 只取获准使用且与当前条件相关的经验或原始来源 |
| 实际修改技能、版本变化异常或评估方法 | [方法更新](method-updates.md)相应部分 | 日常版本相同直接复用，正常轮次不再读取本细则 |
| 品牌演示版式或固定模板 | [演示模板](presentation-template.md) | 实际成品制作再调用对应工具与技能 |

## 涉及报告时识别类型

总体报告、电商、产地场景、渠道、供应链交易及结题汇报的职责由入口1+4+1说明。类型确定后仍以本轮动作选主方法。电商订单中的仓配问题不扩成整份交易中心；定位已确认的专题直接深化当前缺口。同一报告不同章节可以处于不同进度，证据不足只回补相关部分。

## 执行组织

实际准备委派、并行搜索、动态调度或独立评价且已有授权时，再读取[工作组织](agent-orchestration.md)。普通方法读取与制作表格直接执行。工作卡需要传递来源、权限、责任、预算或依赖时，再取[工作单元](work-units.md)；不从工作卡返回此路由重新展开所有方法。

需要开发可复用表格、组件或代码接口时，查项目现有组件与[工作单元的复用约定](work-units.md#执行组织与复用)。普通正文、一次性表格优先复用已有样式和字段，无需为此额外加载组件治理。

## 方法和外部技能如何调取

本包自带研究与经营方法。外部技能只补当前真实缺口，例如复杂因果判断、写作、表格建模或PPTX、HTML、DOCX制作；先确认环境能力及范围。普通提纲不因可能使用表格而自动加载表格技能，品牌分析也不连锁加载所有通用推理与战略方法。

## 简短路由记录

复杂或持续任务沿已有记录写：本轮交付、当前缺口、主方法及章节、新增补充方法的理由、已完成与下一单元。仅在路由不清或评估加载效果时记录详细读取轨迹，区分公共方法、项目材料和外部证据。

后续轮次复用目标、定位、数据和已读方法。入口版本相同无需重复读参考；版本改变、任务转阶段或新证据推翻相关判断时，只刷新受影响部分。完成当前交付后停止补充读取。
