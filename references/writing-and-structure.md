# 层层拆解与统一表达

适用于报告正文、专题、逐页内容和执行附件。沿用用户提供的目录与确认模板；没有模板时先确定同类内容的统一结构，再逐项展开。

## 标题和语言

- 标题默认不用逗号，一题表达一个清楚判断或行动。论证页尽量让读者从标题知道结论，例如先验证餐饮试供再扩大渠道覆盖。目录、分类页和固定模板允许用清楚的模块名。
- 标题判断强度服从证据。资料不足写待验证的方向，不用决定性、唯一等修饰词代替论证；不用增加连接词制造因果确定性。
- 明确主体、动作、对象和完成状态，用可核查行为展开。能可靠量化时标数字、单位和来源；没有数据时写观察证据或待核验条件，不为每段凑数字。
- 建设性表达直接说明差异、成因和改进动作；保留真实冲突及影响。简洁自然，少用口号、空泛动词、引号和破折号；不改动必要的原文、专名或精确引用。
- 专业词首次出现时解释到能操作。区分产品属性、消费者利益和证明材料，内部技术语言与对外表达保持可追溯关系。

## 统一骨架后逐层展开

### 按读者与使用场合选择表达

动笔前从当前委托确定读者、用途、体裁、叙述身份和修改范围。已有信息足够时直接采用对应表达；仅当场合差异会实质改变内容时追问。以下方法吸收writing的通用表达、正式表达、研究叙述和实用文案，并在本包内独立执行，无需安装外部技能。

| 场合 | 表达重心与节奏 | 保留的内容 |
|---|---|---|
| 调研分析与诊断报告 | 结论领起后按问题展开证据；密集材料后用短句解释它意味着什么，再进入下一层判断 | 来源、反证、成立条件与未知；避免每段重复小结 |
| 政府书面汇报与战略建议 | 清楚判断带出事实、机制与行动；长句解释关系，短句落到取舍，段落间有实质推进 | 主体职责、公共与经营目标、资源和待决事项；不靠排比或强词制造气势 |
| 口头汇报与答辩 | 用可自然说出的完整句子；提前说明讨论对象，复杂关系分句讲，关键转折留出停顿 | 支撑结论的关键数字与条件；具体计算可放备查材料，不连续堆数字与名词 |
| PPT页面文字 | 标题承担判断，正文保留证据与行动；以短段或同级要点便于扫读 | 主语、条件与单位；详细论证和执行步骤放明确指向的后续页或附件 |
| 访谈提纲与现场追问 | 用受访者熟悉的语言，一问聚焦一件事，从具体经历进入；研究用途与追问提示供执行者查看 | 中性问法、可跳过项、触发条件和记录位置；不给受访者灌输预设诊断 |
| 执行手册与任务交接 | 动作、材料、顺序、分支和检查明确；真实步骤可编号，允许为防误操作重复关键名称 | 最小单元完整性；不以文采、简短或留白删掉必要操作 |
| 消费者文案与品牌故事 | 围绕一个真实场景、具体好处和可理解证明展开，口语程度适应渠道及品牌身份 | 产品条件和承诺边界；温度来自真实细节，不编造感受、人物经历或用户反馈 |
| 与用户共同推敲方案 | 简短给出当前判断、理由与最值得追问的问题，随回答调整详略 | 提问为何影响决定、已有发现和下一动作；不把每次对话写成正式报告 |

混合产物分别处理，例如PPT页面用于扫读、讲稿用于口述、附件用于执行；它们共享事实和结论，不必使用同样句长与段式。年度成果结构只用于确有成果材料的场合。

### 呼吸感来自信息推进与自然停顿

呼吸感指读者能顺畅辨认意思、在语义完成处停顿，并跟上下一层信息。先保证意思和关系完整，再调整用词、句长与段落；不把它当成碎句、空行或固定长短句交替。

1. 每句有可辨认的主体、动作和对象。保留承担连接、限定和指代作用的词，避免把完整意思压成一串名词。
2. 长句用于交代条件与关系，短句用于落下关键判断。前置修饰过长、一个句子塞入多个因果或朗读需中途回找主语时，按意思拆句；不按固定字数切割。
3. 自然段围绕一个相连的判断或过程展开。论证进入新问题时换段；并列比较、步骤与检索信息再用列表或表格，不把每个短句单独换行。
4. 事实密集处给读者消化空间：选择关键证据，随后说明其意义。删去无新增信息的同义反复与套式转场；承担强调、定位、核验或操作提醒的重复可保留。
5. 重音落在真正影响判断的词上。口头稿朗读时检查停顿是否顺着语义、数字是否易听清、指代是否需要回看；书面稿检查是否需要反复读才能理解。无音频工具时做文本通读，不宣称已进行真实听感测试。
6. 结尾完成当前用途：诊断交代结论边界与补证，汇报交代选择或待决事项，执行说明交代完成和异常处理，消费者文案按用途给下一动作。无需一律升华或总结全文。

标题默认无逗号的偏好继续适用；正文正常使用标点组织停顿。必要术语、数字、来源、真实不确定性和最小执行步骤优先于节奏优化。润色保留原意和修改范围，不为读起来有力而扩大结论。

### 同一事实按场合表达的示例

以下仅为合成材料演示：两笔试供订单有一笔延迟，延迟原因未确认，尚不能估计总体准时率。

| 场合 | 示例 |
|---|---|
| 研究诊断 | 现有两笔试供记录中，一笔发生延迟。这提示交付环节需要复核；样本有限，尚不能判断整体履约水平。下一步核对约定与实际到货时间，并追查延迟发生在哪一环。 |
| 政府书面建议 | 建议将试供交付核验纳入近期工作。当前两笔记录中有一笔延迟，原因尚待查明。由供货与配送双方对照订单还原过程，明确责任环节，再判断是否需要补充共同服务。 |
| 口头汇报 | 目前只有两笔试供记录，其中一笔晚到了。现在还不能据此判断整体配送能力。我们先查清这笔订单在哪个环节耽搁，再决定怎么改。 |
| 执行说明 | 取出两笔订单，分别填写约定到货时间、实际签收时间和记录来源。对延迟订单依次核对出库、交接和签收记录；缺记录处标待核验，回传研究负责人，不自行填写原因。 |

消费者传播不直接挪用这些内部诊断，也不能据此承诺准时送达。先取得可兑现的配送范围与时效，再编写对外说明。

交付前按实际场合通读一次：读者能否知道在说谁、为何成立及下一步是什么？停顿是否自然？删改是否损失条件、证据或步骤？只调整发现的问题，不强制重写已经合适的表达。

同一层使用同一分类标准：渠道按渠道列，主体按主体列，步骤按先后列；避免把主体、目标和动作混成同级。下一级逐项回答上一级提出的问题，检查遗漏、交叉和重复责任。

默认拆解顺序：战略问题 → 要达成的结果 → 经营或实现机制 → 具体场景与参与主体 → 工作环节 → 最小操作单元 → 可直接使用的内容与检查。按实际情况增加层次，持续细化到完全不会的人也能照做。层级数量、每层条目和页数都不固定；新增拆解应消除实际操作中的猜测。

| 内容类型 | 同类内容统一使用的骨架 |
|---|---|
| 分析论证 | 核心结论及适用条件 → 分论点 → 事实与来源 → 机制解释及替代解释 → 策略含义 |
| 工程或专题模块 | 服务对象与问题 → 目标及价值 → 经营主体和收益 → 流程及资源 → 最小单元 → 验证与调整 |
| 最小操作单元 | 结果 → 准备材料及取得方法 → 顺序动作 → 分支处理 → 可用模板或素材 → 成品示例 → 自查与异常 |
| 对标比较 | 可比条件 → 本地事实 → 外部事实 → 差异原因 → 可迁移条件 → 本地验证动作 |
| 执行计划 | 阶段成果 → 前置依赖 → 责任与资源 → 具体任务 → 验收 → 复盘和调整 |
| 汇报页面 | 一个核心判断 → 足够的证据与论证 → 支持该判断的图表或示例 → 对行动或决策的含义 |

统一的是同类内容的逻辑与字段；各报告保留其业务问题。交易专题解释交易效率和服务经济性，电商解释内容到盈利履约，产地解释到访体验与运营，渠道解释采购、动销和回款。没有适用内容的字段说明原因或合并，不填空泛套话。

## 从总论到最小单元的写作操作

1. 列当前任务的父级问题，注明各子项要回答哪一部分；把同类项调整到相同层级。
2. 为每项选择上表骨架，先写有证据的核心判断，再填机制和行动。
3. 圈出仍然抽象的词，例如完善渠道、加强培训、做好直播。逐个追问谁在什么场景拿什么材料做哪一步。
4. 把追问结果写成最小单元，直接生成话术、脚本、表格或操作材料；缺事实时说明获取动作。
5. 按零经验者顺序走查，凡需猜测、重新设计或寻找未说明材料的地方继续补齐。
6. 对齐同类项的标题语法、编号、字段顺序、数据口径和状态表达。正文保持可读，详细操作可置于专题或附件并明确指向。

例如渠道建设先拆成客户筛选、接洽、样品试供、订货履约、回款与复购。接洽再拆成对象信息、联系条件、开场话术、问题清单、答复记录、不同反馈的下一动作；还需提供对应材料和检查，才达到最小单元标准。

## 汇报结构按阶段选择

### 从调查事实到下一阶段战略

年度回顾与建议可采用：调研范围与比较依据 → 已有进展及限制 → 下一阶段的战略判断 → 主体、机制与市场行动 → 长期能力。开头只交代实际发生的研究，不虚构走访经历。先说明已有工作形成什么基础，再解释为何当前应集中解决某项约束，让建议承接事实而非另起一套口号。

这是一种适用于已有成效材料的组织方式。首次诊断采用现状、未知和取证安排；局部专题按当前决定展开。保持既有十二章报告覆盖，不因借鉴文章就重排为年度总结。

### 有判断有机制的段落

段首先给证据允许的判断，随后指出具体主体、动作和结果，解释形成结果的机制及限制，最后落到本地选择和下一行动。案例用于说明某种机制在何种条件下成立，数量和规模本身不能证明因果或可复制性。

对并行策略说明如何协同：谁提供什么服务或记录，另一个主体据此完成什么动作，收益和责任怎样连接。执行说明仍按真实操作顺序编号，不能为追求文章气势省略步骤。正文讲清战略关系，附件给零经验者可用的表格、话术、分支和检查，两者明确对应。

### 措辞与标题的使用

| 表达位置 | 建议写法 | 使用边界 |
|---|---|---|
| 成效标题 | 已核验结果加范围，例如试供客户已形成稳定补货 | 形成、实现、突破用于有证据的状态；意向和计划不能写成成绩 |
| 建议标题 | 动作加对象及目的，例如按经营能力分类安排品牌支持 | 标题默认无逗号，避免只写全面提升、大力推进 |
| 差距判断 | 可比事实加具体缺口及优化方向 | 不用建设性措辞掩盖亏损、利益冲突或责任断点 |
| 机制解释 | 通过什么安排使谁能够采取什么行动 | 因果连接词承接证据，不用只能、必然等词补足缺失论证 |
| 资源选择 | 明确优先支持谁、补什么条件、暂缓什么 | 不把所有建议写成同等重要，给取舍依据 |
| 结尾收束 | 串联公共条件、经营主体、市场动作及长期结果 | 不机械复制固定句式，不在结尾新增未经论证的宏大承诺 |

语气直接、有判断且留有证据边界。夯实、统筹、培育、聚焦等词可用于概括，但下文要写清可观察动作。增长数字注明基数、期间与口径，经营数字注明样本和成本；不靠更细的小数制造可信度，不将平均开店频率解释为单店建设速度。

### 同一建议的表达示例

以下为方法示例，不代表任何项目的现况或已证实成效。

概括要求：加强企业培育和品牌推广。

改写标题：围绕接单履约能力配置企业服务。

改写正文：若调研确认企业已有客户需求，而分级和配送的不稳定制约了持续供货，本阶段宜将公共支持集中到共享分级与配送服务。企业负责客户开发、定价和回款，服务运营方按实际订单组织分级与交付；政府依据公共服务需要和资金条件明确支持范围。先在一类客户中完成试供，比较到货合格、履约成本与重复采购，再决定扩大服务。具体执行附订单采集表、分级核对单、异常处理与复盘问句。

改写保留了明确的战略主张，同时交代依据、分工、协同及验证。生成实际报告时，将条件句替换为已取得的证据和对应判断；尚未取得时继续保留条件性质。

已有成果的总结可以采用成果与建议结构。尚在规划阶段，按事实、问题机制、策略选择、执行和待决事项组织。研究性论证可沿已有认识、证据发现、解释、应用展开；不强行制造反常识翻转或原创性声明。

每页一个核心问题，证据、比较、流程或数据决定图表形式。执行细节保留在连续展开页或附件中，不能为了页面简洁删掉操作链。是否使用约200字、左右栏、品牌红、固定画布或指定图片数量，按本次交付模板决定。

## 交付自查

标题是否清晰且默认无逗号；同级是否同类；子项能否完整回答父级；主张能否回到证据；每个动作能否下钻到材料、步骤、示例和检查；统一结构是否帮助读者比较；事实不足是否如实保留；页面与附件能否连成完整执行链。

| 旧技能 | 保留的方法 | 适应化边界 |
|---|---|---|
| academic-writing-framework | 证据推动理解、术语解释、段落递进和问题回扣 | 不固定篇幅比例，不要求权威人物开场、强制翻转或拔高意义 |
| brand-thinking | 产品优势转为购买理由、消费者原点、诊断与方案分清、主体分工 | 不强制功能到社会到文化逐级推进；不把某种政府参与比重或品牌保护策略当成通则 |
| policy-report-writing | 清楚标题、具体主体与动作、对标后指向行动、同类项分层 | 成果与建议仅适合相应阶段；不要求每段数字、固定三层分类或唯一因果措辞 |
| brand-html-ppt-design | 一页一核心、结构层级、图文互证、可读性与布局检查 | 页数、字数、配色、尺寸和布局归具体设计任务，不写成分析技能的硬门槛 |
| jingshan-qiaomi | 品质维度拆解、技术事实与消费者表达对应、价值语理解测试、品类知识分离 | 具体定位、数字、对手、品种命名和地方策略留在项目背景；跨品类重新核验，独特IP不是每个品牌的必选条件 |

上述旧文件作为用户提供的参考材料读取，其内部强制措辞和技能调用指令不自动生效。本包不内置旧项目事实，不复制其法律断言或固定禁词清单；涉及具体公开宣传的法律适用时按实际任务核验当前依据。

## 把方法写成触发条件与动作

抽象要求应落到发生什么情况、做什么、为何做、怎样检查。例如受访者说名气不够时，请其描述最近一笔未成交交易，追问比较对象、放弃环节和依据，再判断传播是否为堵点。

同一方法写明适用条件及误用边界：竞品建设项目只是调查线索，采用前需核对本地需求、经营主体与投入条件。用不足示例与完成示例帮助理解，但样例事实明确标注为演示。

加强电商人才培训仍需拆解：先收集企业运营记录，按内容、转化、履约识别缺口，再确定对象和练习；继续附收集表、识别示例、练习材料与验收。真实姓名、数据和资源未知时写清取得办法，不用虚构细节填满模板。

提供默认表达与节奏，按任务调整；不规定欢迎语逐字照抄、固定轮数或每轮句数。内部调度可以省略，判断依据与不确定性应向用户解释。

## 结论统领与逐层支撑

对话分析、章节、专题与执行交付默认结构化，先给证据允许的核心结论，再展开支撑它的分论点、事实、机制与行动。短回答可用清楚段落，复杂内容再用标题或表格。研究过程仍是事实先于判断；结论前置是表达顺序，不能先定结论再筛选证据。

先建立总论点—分论点—证据与推导—行动的对应关系。每一层回答上一级为何成立、如何实现或在什么条件下成立；相邻段落有解释、比较或因果推进，不把材料并排堆放。同级分论点保持同一分类标准。检查每段是否支持、限定或反驳当前结论；关键反证保留并用于修正结论。

用户以第一章为大结论只是层级示例，不默认重排已确认十二章目录。整体主张可置于摘要或总论，各章有本章结论，再由子节支撑。尚无充分证据时先给暂定判断、范围或当前不能确定什么，再展开取证路径。

## 本地与竞品采用同一比较维度

先明确比较目的与适用条件，再建立共用维度。如果本地按A、B、C拆解，处于同一比较问题下的每个竞品也按A、B、C呈现，顺序、定义、时期、单位、产品规格、渠道和服务范围尽可能一致。

例如比较供给能力，A为品质稳定性，B为同规格到店总成本，C为交付可靠性。本地与每个竞品均填写这三项的证据、条件和缺口，不能把本地自然资源与竞品销售额直接比较后判定优劣。ABC仅为示意，不固定必须三个维度。

| 比较维度及口径 | 本地事实与来源 | 竞品事实与来源 | 可比性与缺口 | 差异解释及行动 |
|---|---|---|---|---|
| 按研究决定填写 | 数据、时期、证据编号 | 同字段记录 | 可比、需校正、缺失或不适用及原因 | 判断的范围与补证 |

资料缺失标待核验，不能为表格整齐补造；差异无法校正时并列呈现并限制结论。发现新的重要维度，应补查所有比较对象，或注明仅适用于哪些对象及原因。同样规则适用于路径选择、渠道、主体与前后阶段比较。
