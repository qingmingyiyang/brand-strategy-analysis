# 经营与现金的完整周期核算

在判断能否赚钱、现金是否够用、保本量、主体净收益，或复核经营数字时使用。先完成本轮决定需要的核算；长期设施、投资回收和公共投入比较再进入[投资经济性](investment-economics.md)。品牌文字润色和访谈提纲准备通常复用已有基线即可。

## 单元一 先确定算谁与算多久

**结果**：一张口径卡和一条业务时间线。它们决定哪些金额属于这次核算。

1. 写清决策：试供是否值得继续、门店能否常态经营，还是运营主体是否需要补充资金。
2. 确定核算主体与边界。经销商自营收入、平台服务费和全产业交易额分别记录；供应方与采购方的同一笔款项对账，汇总时按所选边界去重。
3. 确定分析单位、期间、币种、数量单位、价格与税口径，区分实际、预测和教学假设。注明收入按哪种交易角色及履约依据归属，成本包含哪些项目。
4. 从采购或生产投入开始，画到交货、销售、退换货、结算、库存处置与售后责任结束。区分经营归属期间、实际收付日期和观察窗口。按月报告可以保留期末余额与后续结算安排，完整周期靠跨期衔接实现。
5. 遇到种养周期、淡旺季、投产爬坡或长账期，选择能够覆盖决定性变化的期间。若只取得旺季记录，先交该期间结果，再用月度情景说明外推条件；全年预测逐月或逐季求和。

| 口径卡字段 | 填法 |
|---|---|
| 要作的决定、主体和边界 | 谁用结果决定什么，哪些业务包含或排除 |
| 单位、期间和观察截止日 | 一单/公斤/店月等；明确起止，未知到哪一天 |
| 交易角色、收入与成本范围 | 自营/代理等；列净收入、费用、折旧、劳动及税口径 |
| 期初余额 | 可动用资金、存货、应收、应付；已有投入与未来增量分开 |
| 周期与未结事项 | 生产、销售、账期和售后；期末剩余项如何承接 |
| 来源与关键假设 | 材料位置、数字归属、取数人和失效条件 |

**检查**：另一人能说清算的是谁、哪个期间、哪批业务，以及期末留下了什么。小试供只算增量费用时注明范围；长期常态经营再补持续人工、维护和固定资源，避免把试办结果直接当成规模经营利润。

## 单元二 把单笔贡献接到期间结果

**准备**：成交与履约记录、采购和库存、退款、费用、人工、设备、租赁与结算资料。缺数保留变量，并明确找谁用什么记录补齐。

1. 每批记录数量和归属期间。按已售业务匹配货品成本，采购付款先进入现金记录；未售存货及损耗分别承接。自产农产品按生产批次与出成率核算，生物资产等具体计量交专业人员按适用制度核定。
2. 列净收入R与对应变动成本V，确认平台扣点、赠品、退货、破损、冷链、增量人工和售后费用。退款若已冲减收入，费用栏只保留仍实际发生的配送、耗材及处置等。
3. 列同期间固定费用F，注明是否包含租金、持续人工、维护、折旧、利息及税项。共享设施按合理用量或服务规则分配，比例有依据；总体汇总只记一次。劳动现金支出和劳动机会成本分别展示，避免双重扣减。
4. 计算单位贡献C = R − V。单一产品且口径稳定时，期间贡献 = Q × C；经营结余 = Q × C − F。多个产品按各自数量与贡献求和后减F。结果名称与已纳入项目相符，例如税前经营结余；会计净利润需补足对应会计项目。
5. 当C大于0且贡献和固定费用在相关容量内稳定，保本业务量 = F / C，不可分单元向上取整。多产品按明确销售组合求加权贡献；新增班次、设备或人员触发台阶成本时分段重算。C不大于0时先改变模式。
6. 保本量与需求、可售供给、损耗、产能、配送容量和账期同时比较。物理销量、结算销量、退货销量以及加工前后重量先统一，再进入公式。

| 参数或事项 | 数值、单位与期间 | 来源及实际/预测/假设 | 归属业务及承担主体 | 未纳入项与补数动作 |
|---|---|---|---|---|
| R、V、Q、F逐项列 | 固定口径 | 订单、报价、费用或公式 | 指向批次与角色 | 谁取得哪份记录 |
| 存货、损耗与退货 | 数量及价值另列 | 盘点、损耗及售后记录 | 确定发生期及成本承担 | 未售、过期、退货去向 |

**演算**：一单收入100元，货品60、包装5、配送12、手续费3，贡献20元；月120单、固定费2000元，结余400元，保本100单。配送升到17元后，贡献15元，结余−200元，保本至少134单。教学假设费用范围固定、无其他成本。只要真实记录改变一个参数，就按同一公式重算。

## 单元三 逐时点核对现金与期末承接

利润回答业务收入能否覆盖归属成本，现金回答到期能否付款。把两者各自算清，再解释差异。

1. 记录期初可动用资金，受限资金另列。沿业务日期排供应付款、工资、租金、税款、退款和客户回款；有垫资或集中采购时，细到可能出现资金低点的日或周。
2. 投资、融资和经营收付分栏。设备购买是相应现金支出，折旧通常不产生当期付款；借款到账、资本投入及借款本金偿还各自记录。融资解决缺口的安排与业务创造的收入分别呈现。
3. 先计算本次新增筹资前余额：期末余额 = 期初余额 + 已有及业务安排的现金流入 − 到期必须支付的现金流出。排除拟为填补本次缺口新增的借款和资本到账，保留已有债务到期本金、利息等必须支付项；逐时点计算最低余额。给定最低运营现金要求B，补足需求 = max(0, B − 预测最低余额)；再列为本次缺口已落实和待确认的新增筹资，单独生成筹资后现金表。使用月度合计时，所得缺口可能低于月内峰值，明确当前粒度。
4. 核对跨期变动，解释经营结果与经营现金流的差异。简化桥接可从经营结果加回已扣除的非现金费用，减经营性存货与应收增加，加经营性应付增加，再按实际口径调整预付、预收、税和其他项目。该桥接用于发现遗漏，正式分类按适用制度核定。
5. 逐项结转期末库存、应收、应付、售后义务、押金和预付款。延长现金观察到关键款项结清，或在报告中写明下一期间的承接日期、金额及责任。观察结束时仍未售的货品保留库存与处置情景，不能预先按预计销售额计为现金。

| 日期或期间 | 期初现金 | 经营收付 | 投资收付 | 融资收付 | 期末及最低余额 | 未结事项与来源 |
|---|---|---|---|---|---|---|
| 逐时点填 | 与上期衔接 | 按实际日期 | 含设备及押金等具体分类 | 到账、偿还分开 | 先本次新增筹资前，再补资金方案 | 回款、库存、欠款及售后 |

### 完整算例 从库存到回款

假设一家自营供货商，金额为元：期初现金3000，无存货与欠款。1月2日购入150件，每件60并支付9000；1月卖出100件，每件100，其中8000于1月20日到账，2000于2月10日到账。销售相关变动费用2500于1月25日支付，固定费用1000于1月31日支付。余下50件完好，单位成本仍60。假设无税、折旧、融资、退款及其他收付，2月仅结清上述应收。

1. 1月经营结果：收入10000 − 已售货品成本6000 − 变动费用2500 − 固定费用1000 = 500。
2. 1月期末：存货3000、应收2000；经营现金流8000 − 9000 − 2500 − 1000 = −4500。桥接为500 − 存货增加3000 − 应收增加2000 = −4500。
3. 本次新增筹资前现金顺序：3000 → 采购后−6000 → 回款后2000 → 变动费支付后−500 → 固定费支付后−1500 → 2月回款后500。最低现金−6000；以最低要求0计算，至少要在采购付款前安排6000的资金，月末1500缺口不足以描述峰值。负数是所需融资的演算，真实执行应在付款前取得资金。
4. 2月回款只减少应收，不再次形成1月这批商品收入。余下库存3000还须在后续销售或损耗发生时处理，不能把它视作已到账收入。

## 单元四 复核数字再写经济结论

核算与品牌判断分步进行。先整理口径和计算表，再针对漏项、周期与现金独立复算，最后把核算结论交回品牌方案；品牌论证有力不能替代经济检查。复杂委派沿当前权限和资源执行，单代理也能在另一遍复核中完成。

1. **边界**：主体、单位、期间、价格及实际/预测一致；跨主体转移和共享投入完成去重。
2. **完整性**：销售与未售库存、损耗、退货、人工、淡旺季、固定维护及其他适用成本逐项有数据或明确缺口。
3. **周期**：收入和成本匹配，收付有日期，期初期末相接；采购、售后、长账期和未结责任得到承接。
4. **可行性**：保本量与需求及容量比较；最低现金、资金到账、恢复库存及补贴结束后的持续条件有依据。
5. **敏感性**：改变最影响决定的成交价、业务量、损耗、配送、账期等参数，明确情景为何合理；联合情景检查它们是否可能同时发生。
6. **交付**：给结论、适用范围、参数及来源、公式、周期表、缺口与取数动作。关键缺数时提供条件性结果，例如在销量达到Q且回款不迟于某日时可继续，暂不生成无法支持的回报率。

## 多情景重复复算工具

跨期回款、月内资金低点或多组经营参数需要反复复算时，可使用[经济计算器](../scripts/calculate_economics.py)。少量简单计算沿用上文公式即可。工具分别接收现金和经营输入，采购付款放入现金模块，已售单位成本放入经营模块。

1. 复制[合成教学情景](../evals/fixtures/economics-scenarios.json)到项目工作目录，保留本轮需要的情景与模块。逐项换成真实材料，未取得的数字先补数，不填成零。
2. 每个情景填写 `name`、`subject`、`currency`、`monetary_unit`、`nature`、`source` 和 `basis`。`nature` 使用 `actual`、`forecast` 或 `assumption`；`basis` 写明税、价格及纳入范围。金额统一使用所填币种和金额单位，不在同一情景混用元与万元。金额推荐写成字符串，如 `"3000.50"`；无该项收付或成本经核实后显式填 `"0"`。
3. `cash` 的 `periods` 按日期连续覆盖观察窗，交易按 `date` 与同日 `sequence` 严格递增。`amount` 填非负数，`direction` 填 `in` 或 `out`。`category` 区分 `operating`、`investment`、`existing_financing` 和本次补缺口的 `new_gap_financing`。已有到期债务仍进入筹资前余额；本次新增资金及其窗口内约定还本付息只进入筹资后余额。每项可补 `source` 和 `nature`，未补时沿用情景口径。同日顺序应有支付记录或明确假设，工具据此计算资金低点。
4. `operating` 填单产品稳定贡献模型 `single_stable_product`、数量单位、是否不可分、成本范围和顺序期间。每期显式给数量、净单位收入、已售单位变动成本与固定成本。不可分业务量向上取整；非正贡献返回 `no_positive_contribution`，保本量为 `null`。多产品、台阶成本另建适合的测算，工具不代做加权或容量判断。
5. 在技能目录运行以下命令，再将结果中的情景名称、主体、来源与期间带回决策底稿。

```powershell
python scripts/calculate_economics.py "项目目录/经济情景.json" --output "项目目录/经济结果.json"
```

JSON 中计算结果的金额保存为十进制字符串，回显的原始整数仍为JSON整数；输入金额统一使用字符串可保持表示一致。`additional_funding_need` 是最低要求与筹资前低点的差额；`remaining_funding_need` 复核已输入新增资金的到账时序，资金晚到仍会留下早期缺口。期末余额逐期承接，逐笔余额可用于回查。`operating_surplus_within_cost_scope` 表示所填成本范围内的经营结余，未售存货和后续责任继续在项目材料中承接。结果保留输入口径，不从现金自动推导利润。

复现教学输入：

```powershell
python scripts/calculate_economics.py evals/fixtures/economics-scenarios.json --output "项目目录/教学复算.json"
```

基线应得到现金低点−6000元、最低要求为0时补足6000元、2月回款后500元；经营模块独立得到1月结余500元。投资模块的字段与结果解释见[投资经济性](investment-economics.md#等间隔投资复算)。

## 口径参考

存货在销售时与相关收入匹配的原则参考[IAS 2说明](https://www.ifrs.org/issued-standards/list-of-standards/ias-2-inventories/)；利润与现金、经营投资融资及非现金项目的区分参考[IAS 7说明](https://www.ifrs.org/issued-standards/list-of-standards/ias-7-statement-of-cash-flows.html/)。这里用它们帮助检查管理测算中的归属和漏项，项目法定会计、税务及农业资产处理按实际适用制度与专业确认执行。
