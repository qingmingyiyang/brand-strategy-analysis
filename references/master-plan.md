# 十二章总体规划与十大工程

用于完整总体规划的覆盖检查。信息缺失时保留章节并标出待核验项，不用推测填满。局部任务无需展开所有章节。每章以影响哪个决定收束，避免资料堆积。

| 章 | 应覆盖的分析单元 | 应形成的判断或产物 |
|---|---|---|
| 一、品牌所在行业的现状 | 行业规模、增速、生命周期；品种类型与产品功能；集中度、季节性、供应链等主要特征；主要品牌竞争；消费者选择特征；趋势与规律 | 明确品类和市场边界、主要替代品、购买标准、竞争结构及趋势的不确定性。不能把行业增长直接当成本地机会 |
| 二、本地现状分析 | 产业规模；市场与行业状况；产品与品种构成；生产要素与方式；代表性主体；推广方式；政府角色；品牌名称、注册、使用与授权事实；基础设施；效率；优势与挑战 | 画出生产到消费的交易链，定位损耗、成本、需求匹配和利益分配的约束；区分资源存在与可商业化优势 |
| 三、品牌定位规划与发展目标 | 独特性；需求点；竞争机会；核心价值；价值表达论证；价值表达；形象设计；成长周期；总目标；长中短期目标 | 比较候选定位并选择；用产品事实和能力证明承诺。形象部分先交设计简报，实际Logo和包装按委托制作；目标区分基线、预测和承诺 |
| 四、指导思想与十大工程 | 指导思想；下表十项工程 | 给出战略原则、工程选择、依赖顺序和资源优先级。这一章是总览，五至十一章展开其机制，避免重复预算 |
| 五、品牌能力规划 | 自然资源优势；品种多元化与需求适配；品质标准体系；种养殖工艺与社会化服务 | 将价值承诺翻译成可稳定交付的品质、产能、服务和组织能力；标明现有能力、缺口与建设责任 |
| 六、产品与大单品打造 | 产品体系、产品矩阵、大单品候选 | 按人群、场景、规格、品质、价格、渠道和经济性定义产品。引流、利润、形象是可选角色；大单品需验证需求、稳定供给、履约和贡献利润 |
| 七、品牌认知规划 | 已有认知评估；价格与品质判断；信息接受特征；功能认知；社会认知；文化认知 | 区分消费者已有认识与希望建立的认识，明确障碍、证据和触点。功能、社会、文化价值按人群需要选择，不设固定升级顺序 |
| 八、品牌推广规划 | 文化故事；品牌推广设计；年度节会与主题；评价发布；公共关系；品鉴体验中心；互联网；媒介选择；嘉年华；包装媒体化 | 逐项选择适用手段，说明受众、信息、行动入口、预算及效果观测。评价必须有明确方法和来源，故事须可核验；活动数量不是效果 |
| 九、公平竞争的市场机制 | 准入、信息披露、交易规则、定价与结算、质量责任、投诉退出、利益分配、监督 | 说明哪些规则降低交易成本并保护参与者；检查关联交易、排他安排和补贴依赖。涉及具体法律适用时另行查询当前权威依据 |
| 十、企业生态建设 | 本地主体；国资平台；龙头企业；电商企业；专业分包企业；区域外企业招引 | 逐类明确能力、参与理由、收益、投入、协作关系和退出条件；国资平台边界由公共目标、商业可行性及实际职责决定 |
| 十一、品牌政府支撑规划 | 登记保护；授权管理；行业协会；部门分工；基础设施；财政金融；人才机构与培训；区域奋斗文化；技术和文化研究院 | 区分政府公共服务、市场经营和协会治理；机构、研究院和设施均需证明实际需求、持续经费与运营主体，不因模板存在就设立 |
| 十二、三年品牌打造行动计划 | 三年阶段目标、关键行动、责任、资源、依赖、里程碑与复盘 | 先列已知基线与约束，再排年度推进；跨年投资考虑现金流与能力形成时间。年份可随任务调整，不能凭空承诺增长率 |

## 十大工程选择表

每项记录采用、试点、后置或不适用，并说明依据。下列问题是诊断入口，不是建设指令。

| 工程 | 关键判断 | 验证或交付方向 |
|---|---|---|
| 品牌提升 | 认知缺口是否真正影响购买？ | 购买理由、信任证据、触达至交易的路径 |
| 企业生态 | 哪种专业能力和利益连接缺失？ | 主体分工、参与经济性、合作与退出机制 |
| 产品创新 | 什么具体场景或需求尚未满足？ | 产品简报、样品、真实购买与复购反馈 |
| 品种集成 | 品种能否匹配市场且适应当地生产？ | 品种需求矩阵、试种试养、周期和风险 |
| 供应链与交易中心 | 哪个成本或履约约束需要共同解决？ | 服务流程、单位经济、轻资产试点、设施条件 |
| 内容与生态电商 | 内容带来的订单能否盈利履约？ | 内容到复购闭环、供给组织与订单贡献 |
| 千城万店 | 哪种渠道覆盖能有效形成动销？ | 按渠道策略展开，门店数量服从动销与经营验证 |
| 产地场景 | 谁会来、为什么来、来了如何体验与消费？ | 客流来源、体验脚本、运营收益和社区参与 |
| 人才汇聚 | 哪个岗位能力决定执行结果？ | 工作任务、招聘或培养、薪酬来源、留任条件 |
| 质量标准 | 哪些品质差异必须被控制和证明？ | 标准、检验、分级、追溯、责任与纠偏 |

## 跨章闭环

对关键主张检查：第二章发现的问题，是否在第三章形成选择，在第四章配置工程，在第五至十一章具备兑现机制，最后进入第十二章的资源和行动。若某工程不能指回问题与价值承诺，重新判断其必要性。
